# 12 — [上板] 性能调优与文档

**What to build:** 在真实设备上完成长时间稳定性验证和参数标定，并交付操作员手册、装调文档和开发者文档，使非技术人员能独立使用、技术人员能定位故障。

**Blocked by:** 09, 11

**Status:** ready-for-human（性能数据需要上板实测；文档部分 agent 可起草，数值待实测后回填）

- [ ] 连续 100 次扫描（每次约 50 颗豆）无内存溢出、无卡顿，配对率大于 80%
- [ ] 双摄 3 帧连拍的内存占用在 K230D 可用范围内；超出则降分辨率或减帧数，并记录取舍
- [ ] 批量推理每批数量、checkpoint 频率、配对容差 ΔT 三项参数有实测依据，最终值写回配置
- [ ] 操作员手册：开机、开始扫描、停止、查看结果、保存或放弃、诊断页使用
- [ ] 装调文档：豆路对准、光照调整、诊断页看双摄、配对率低时的排查步骤
- [ ] 开发者文档：目录结构、模块职责、配置项说明、如何在主机上跑测试
- [ ] 文档只写已验证的结论，未验证项明确标注；不写获奖概率或未实测的精度
