# 10 — 设置、队列管理与诊断页

**What to build:** 操作员能在设置里改样品重量、查看并删除本地队列项，并进入诊断页手动看双摄预览，用于装调时检查豆路。

**Blocked by:** 06, 08

**Status:** ready-for-human（诊断页的双摄预览需要上板验证；样品重量与队列管理部分 agent 可在主机侧先完成）

- [ ] 设置页可配置样品重量，默认 350g，范围 300–400g，越界输入被拒绝并提示
- [ ] 队列管理页可查看各条记录状态，可删除项；失败项能看到原因
- [ ] 诊断页从设置进入，手动开启后以约 2fps 抓取双摄静态帧并叠加检测框
- [ ] 离开诊断页后预览停止，不占用采集资源；扫描中不能进入诊断页
- [ ] 设置页没有 WiFi 与配对入口
