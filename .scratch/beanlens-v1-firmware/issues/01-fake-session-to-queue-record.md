# 01 — 假会话落盘成队列记录

**What to build:** 在主机上建好固件目录骨架和测试环境，让一个硬编码的「假扫描会话」（16 类计数全 0）能被保存成一条合法的本地队列记录。这是整个 v1 的第一发曳光弹：配置读写、会话对象、原子写入、队列入队一条路径走通，后续所有票都在它上面长。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 固件目录按 ARCHITECTURE-v1 的三层（界面 / 业务 / 采集）建立，主机可直接跑单元测试，不依赖板卡
- [x] 配置管理：首次运行缺配置时给默认值（样品重量 350g、队列路径），读写后内容一致；不含任何 WiFi 字段
- [x] 构造一个假会话并入队后，队列目录里出现一个以幂等键命名的文件，内容是合法 JSON，16 类计数齐全且均为 0
- [x] 幂等键在会话创建时生成一次，格式符合 ADR 0004，之后读回不变
- [x] 写入走「临时文件 + 原子 rename + 保留 .prev」；模拟写到一半中断后，读回的要么是旧内容要么是新内容，不会是半个 JSON
- [x] 用测试证明上述行为，测试只断言外部可见结果

（以上均为主机检查，CPython 3.13.12 + unittest；未在 CanMV 板上验证。）
