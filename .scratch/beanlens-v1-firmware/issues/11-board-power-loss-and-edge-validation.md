# 11 — [上板] 断电与边界验证

**What to build:** 在真实设备上把断电恢复和边界条件逐项跑一遍，证明数据不丢、状态不乱、提示清楚。

**Blocked by:** 09

**Status:** ready-for-human（需要你在板上断电、拔卡、投特殊样本）

- [ ] 断电 5 次，覆盖：扫描中、队列积压、结果页未处理、放弃会话、checkpoint 写入瞬间；每次重启后数据完整、状态正确
- [ ] 扫描中断电后，待机页出现「上次扫描未完成」横幅，可查看或丢弃，且不能保存入队
- [ ] 16 类全 0 的合法会话可正常保存
- [ ] 单类占比超过 30% 不拒收
- [ ] 配对不明超过 20% 时屏幕提示
- [ ] 16 类之和大于豆粒总数时，固件自检拒绝保存并有明确提示
- [ ] 队列满 100 条时阻断新扫描，清理后恢复
- [ ] 频繁 checkpoint 下实测 TF 卡写入延迟，记录数值
- [ ] 所有边界都有清晰提示，无崩溃、无数据丢失
