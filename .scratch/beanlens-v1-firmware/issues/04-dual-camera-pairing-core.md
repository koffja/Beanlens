**What to build:** 给定前摄和后摄各自的一串带时间戳的候选（track），配对逻辑能算出配对成功数、配对不明数和配对率。先用合成数据在主机上验证，不碰真实相机。

**Blocked by:** 01

**Status:** done

验证范围：仅「主机检查」（合成 track，`firmware/k230d/tests/test_pairing.py`）。配对率在真实豆路上是否 >80%、ΔT 初值是否合适，要等票 06 上板实测，本票不声称达标。

- [x] 前后摄时间戳之差不超过 ΔT 才允许配对；ΔT 从配置读取，初值为 2 帧间隔（`time_pair_tolerance_ms` 为 null 时按 csi 帧率换算 2 帧间隔，显式毫秒值覆盖；恰好等于 ΔT 算配对）
- [x] 一对一消费：同一个 track 不会被配对两次
- [x] 落单的 track 计入配对不明，并保证 豆粒总数 = 配对成功 + 配对不明
- [x] 配对率低于 80% 时产生「豆路对准或光照异常」提示；配对不明占比超过 20% 同样触发
- [x] 边界用合成数据覆盖：单侧丢帧、两颗豆几乎同时下落、ΔT 改大改小对结果的影响
