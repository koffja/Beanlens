# 07 — [上板] 16 类推理集成

**What to build:** 配对成功的豆，其裁剪图在板上过 16 类瑕疵模型，输出每类的计数增量，并并入当前会话的计数。

**Blocked by:** 03, 06

**Status:** ready-for-human（需要你准备已标注的瑕疵豆样本并在板上运行；模型端侧部署目前尚未验收）

- [ ] 记录所用模型、nncase、板端运行时的精确版本与文件校验值；训练环境与板端环境分开，不升级用户现有训练环境
- [ ] 批量推理，每批不超过 8 个配对豆，实测内存后可下调
- [ ] 推理输出经预处理、后处理后映射成 16 类计数增量，检测与分类的输出不混用
- [ ] 每类至少 1 颗样本，用 20 颗人工标注瑕疵豆逐颗验证，检测准确率大于 85%，且不能出现全黑豆漏检
- [ ] 未判定的豆不算正常豆；拒判单独计数
- [ ] 结果明确区分「主机检查 / 目标构建 / 上板运行」，不编造性能或精度数字
