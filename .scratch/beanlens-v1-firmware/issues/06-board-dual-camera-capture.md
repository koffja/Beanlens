# 06 — [上板] 双摄 3 帧连拍采集

**What to build:** 在真实 K230D BOX 上，前后两路相机持续低分辨率监视，检测到前景后触发 3 帧短曝光连拍，把带时间戳的候选喂给票 04 的配对逻辑，并实测配对率、标定 ΔT。

**Blocked by:** 04

**Status:** ready-for-human（需要你接板卡、投豆；agent 只能准备脚本和主机侧部分，并必须先核对已装固件的短曝光与两路 CSI 能力）

- [ ] 先核对已装 CanMV 固件是否支持短曝光和两路 CSI，结论写入验证记录；不照通用 K230 API 假定
- [ ] 采集用有上限的缓存和队列（每路最多 3 个候选），裁图复制后及时释放采集缓冲，不保存全部原始帧
- [ ] 手投 50 颗豆：逐颗投配对成功率大于 95%
- [ ] 连续投 50 颗豆：配对成功率大于 80%；不达标则调 ΔT 或触发阈值后复测，把最终 ΔT 写回配置
- [ ] 连续采集 100 次无内存溢出、无卡死
- [ ] 验证记录分别标明「主机检查 / 上板运行」，不把主机语法检查当作板上可用
