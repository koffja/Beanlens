# 豆鉴 BeanLens：相机、训练与批次抽样建议

日期：2026-10-09。本文是资料核对、工程建议与统计计算，不代表相机已经实测、模型已经训练或精度已经验证。设备配置读取结果为 Apple M5、32GB 内存；不记录设备标识信息。

## 1. 建议决策

- 首版选 Arducam B0280 USB UVC、IMX477 12MP，搭配 6mm CS 手动镜头，直接连接 Mac。采购时核对镜头版本：官方产品页面部分标题混有其他镜头套装描述。
- 固定暗箱、漫射可见光、灰卡、固定拍摄距离，比只增加像素更重要。豆体应充分露出；托盘浅凹槽不能遮住待测表面。
- 原型采用固定格位裁切、逐颗分类、正反面合并、人确认、代码统计。无需先训练目标检测器。
- 云端以 Qwen3-VL Plus 为第一基线，GLM-4.6V 同图对照；没有咖啡专用实测证据支持谁更准确。
- 32GB Mac 本地训练重点是预训练小型分类器的迁移学习，不以大视觉语言模型 LoRA 为这几天的主交付。
- 100 格是上料/拍摄单位；一个批次可累计多盘新豆。重复拍同一批豆不会增加独立统计样本量。

## 2. 相机与光学

厂商 B0280 产品资料列出 USB UVC、Mac 原生 UVC 驱动兼容、4032×3040、最高分辨率 10fps、6mm CS 手动镜头、最近对焦距离 0.2m；这足以支持静止托盘原型的规格选择，但实际设备的全分辨率采集和控制能力必须验收。

来源：

- [Arducam B0280 官方产品页](https://www.arducam.com/arducam-high-quality-complete-usb-camera-bundle-12mp-1-2-3-inch-imx477-camera-module-with-6mm-cs-mount-lens-metal-enclosure-tripod-and-usb-cable-b0280.html)
- [Arducam 官方 UVC 选型表](https://docs.arducam.com/UVC-Camera/USB2-UVC-Camera-Kit/Specs-and-Selection-Guide/)

建议采购组合：相机与明确镜头版本、刚性俯拍架、固定暗箱、高显色恒定可见光源与扩散板、灰卡/色卡、两块带方向标记的托盘、可保持每颗豆位置的翻面盖板。ESP32 可控制灯光/按钮；Mac 负责拍摄与计算。不要把 USB 相机直接接 ESP32 当成已验证可行方案。

先搭约 20–30cm 的可调拍摄距离，用实物确认视野、四角清晰度、虫孔可见性，再定托盘尺寸和结构。拍摄必须取得原生高分辨率文件；1080p 预览截图不等于 12MP 原图。目标豆体长轴约 150–250 原生像素作为工程起点，微小孔洞仍可能需要更近拍的局部图。插值放大不能恢复原图没有的细节。

独立设备后续备选为 Raspberry Pi Camera Module 3 Standard、带 IR-cut 的普通版，配 Raspberry Pi 主机。它是 CSI 相机，不能直接当 Mac USB 摄像头；厂商提供固定镜头位置控制。首版不必同时采购两套。

- [Camera Module 3 官方规格](https://www.raspberrypi.com/products/camera-module-3/)
- [官方对焦控制说明](https://www.raspberrypi.com/news/raspberry-pi-camera-module-still-image-capture/)

## 3. 云端模型和可训练范围

Qwen3-VL Plus 官方模型页列出图像输入、结构化输出，并明确模型调优“不支持”。输入样例、参考图片、分类规则属于提示/上下文方法，不是训练该 API 的权重。不能承诺其随着使用自动学习。

GLM-4.6V 官方资料支持视觉输入、可开关思考、工具调用；这些通用能力不是生豆瑕疵准确率证据。公开权重与云端 API 调优能力也不能混同。

- [Qwen3-VL Plus 官方模型信息](https://help.aliyun.com/zh/model-studio/qwen3-vl-plus)
- [GLM-4.6V 官方模型文档](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-4.6v)

建议固定 200–500 颗独立专家标注实物作首轮盲测，各类有足够实例；保持相机、裁切、参考示例、输出格式一致，比较逐类召回率、误报率、待复核比例、延迟与调用成本。另留符合真实瑕疵比例的随机样本评估批次率，不能用人工均衡的分类测试集估计自然瑕疵率。样本数量是原型建议，不是保证精度的统计论证。

格位裁切后的图片按小批发送，附格位 ID、正反面 ID；不让大模型凭整盘图直接猜总数。输出包括可见特征、候选分类、待复核状态。模型自述的置信分数不是已校准概率。

先定义可见表型，如黑变、虫孔、破损、壳形；颜色相近的异常先待复核。允许一豆多个表型，汇总瑕疵豆颗数时同一豆只计一次。照片不能完整替代嗅闻、浮水或其他物理检查，不把肉眼可见异常直接解释为已确诊病因。

## 4. M5 32GB 几天内的训练目标

详见[本地训练一手资料与四日计划](./beanlens-local-training-primary-sources-20261009.md)。Mac 也能探索小型视觉语言模型微调：MLX-VLM 维护者提供 Qwen3-VL-2B 的 LoRA/4bit QLoRA 示例，但这不等于微调 Qwen3-VL Plus API，也不保证视觉细节分类改进；普通示例还会冻结视觉模块。本项目先以小型分类器作为几天内主交付。[维护者训练文档](https://github.com/Blaizzy/mlx-vlm/blob/main/mlx_vlm/LORA.MD)

工程建议：

1. 第一天：固定拍摄条件；专家定义标签；先做正常/可见异常二分类及少数容易区分的表型；取得有唯一 ID 的实物样本。
2. 第二天：完成格位裁切和正反面对应；专家确认标签；按实物 ID 和来源批次分组拆分训练/验证/测试；做 Qwen 与 GLM 基线。
3. 第三天：以 MobileNetV3 或 EfficientNet-B0 预训练权重训练分类头，再视验证表现微调少量层；用 PyTorch MPS。MPS 不支持的算子需调整或回退，训练时长需实测。
4. 第四天：使用不同豆子的留出测试集、最好不同来源批次验证；测逐类召回、误报、待复核率；接入人工确认与批次报告。

每类 50–100 颗独立实物可启动探索；条件允许时扩到每类 150–300 颗以上，再按错误类型补样。这不是充分训练数量保证。每豆多角度照片增加覆盖，不增加独立实物数量。禁止同一豆正反面、旋转图或增广副本跨训练/测试集合。颜色增强幅度应保守，避免抹去黑变、黄褐色等分类线索。AI 标签必须经专家确认，不用模型自己产生的答案证明模型正确。

## 5. 统计口径

本节估计的是“定义范围内的瑕疵豆颗数 / 独立抽检豆总颗数”，不是重量瑕疵率、SCA 等价瑕疵点数，也不是批次验收合格概率。碎片如何作为计数单位需预先定义，否则一颗碎豆变三片会改变分母。

统计计算假设随机、具有代表性的独立取样，且分类已正确确认。真实袋间/位置聚集、取样偏差和模型误差不包含在简单二项区间内。

### 100 颗代表什么

- 大批次、最保守比例 p=0.5，95% 近似误差约 ±9.8 个百分点。
- 100 颗中发现 5 颗：点估计 5%，Wilson 95% 区间约 2.15%–11.18%。
- 100 颗中发现 0 颗：精确单侧 95% 上限约 2.95%；不能宣称总体无瑕疵。
- 不存在“100 颗最多代表多少公斤”的统一对应。批次很大时样本量主要由所需误差、置信水平和真实比例决定。
- 不放回随机抽样的有限总体修正可缩小区间。例如 n=100、未知比例按最保守 p=0.5 规划，要误差约 ±5 个百分点，总体只能约 135 颗。这不是工业批次取样建议，只用于解释固定取样比例的误区。

### 大总体精度规划

近似样本量 n0=z²p(1-p)/E²，z=1.9599639845，E 为绝对比例误差。有限总体修正 n=n0/[1+(n0-1)/N]。这些是规划公式；实际报告使用 Wilson 或精确区间，低比例不能只套普通正态区间。

未知比例，按 p=0.5 保守规划：

| 95% 目标误差 | 独立豆数量 | 以每豆 0.15g 假设换算 | 100 格盘数量 |
| ------------ | ---------: | --------------------: | -----------: |
| ±5 个百分点  |        385 |                约 58g |            4 |
| ±2 个百分点  |      2,401 |               约 360g |           25 |
| ±1 个百分点  |      9,604 |             约 1.44kg |           97 |

0.15g 只是换算示例，必须称本批 100 颗取得实际均重。假设真实比例约 5%，±2 个百分点近似需 457 颗，±1 个百分点近似需 1,825 颗；若真实比例更高，规划会不足，不能把未证实的低比例当作保证。

### 检出与估计不同

若希望真实比例至少为 p 时有 95% 概率检出至少一颗，假设识别完美，n≥ceil[ln(0.05)/ln(1-p)]：

| 真实比例门槛 | 独立样本数量 |
| ------------ | -----------: |
| 1%           |          299 |
| 0.5%         |          598 |
| 0.1%         |        2,995 |

这是检出规划，不是精确估计比例，也不是完整验收抽样计划；验收需要预定可接受率、拒收率、接收数和双方风险。

公式和区间依据：

- [NIST 样本量规划](https://www.itl.nist.gov/div898/handbook/ppc/section3/ppc333.htm)
- [NIST 缺陷比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)
- [NIST 有限总体修正说明](https://www.itl.nist.gov/div898/handbook/prc/section2/old.prc272.htm)

### 一吨批次建议

原型工作方案：累计约 2,500 颗新豆，作为未知比例下 ±2 个百分点的基础目标；实际置信区间仍需结合抽样设计与分类验证。若约 20 袋×50kg，可覆盖全部袋并从不同深度/位置取增量，充分混合、使用适合粒径的分样器随机缩分后检测；保留袋号与取样位置。此处是工程建议，不宣称该具体流程已符合某标准条款。

一吨不意味着要检测固定重量百分比。若每豆假设 0.15g，一吨约 667 万颗，有限总体修正对上述数量几乎无影响。取样时保留小豆、破损与异常豆，不能为了凑齐100个孔而挑选形状规则的豆；未能进入孔位的部分也要检测和记账。

袋装生豆取样本身有 ISO 4072 标准，与本节主动忽略 SCA 350g 的比例计算是两个层次。官方摘要涉及增量取样与样本准备。

- [ISO 4072 官方说明](https://www.iso.org/standard/9786.html)

## 6. 检测效率与误差

- 首版用双托盘轮换：一盘拍摄计算，另一盘上料；一次撒入、轻振单层、确认空格/叠豆、拍摄、保持身份翻面、拍摄、卸料。空格与重复图像不算新样本。
- 目标若设为每盘双面总流程 30 秒，则约 200 颗/分钟、2,500 颗约 12.5 分钟，仅为设计目标，另计取样和人工复核，不能当作实测速率。
- 后续针对大量抽检，改成单层振动盘或短输送带，以分割/检测定位每颗豆并跟踪身份；运动拍摄再考虑全局快门、曝光与同步光源，不能沿用静态托盘规格直接承诺运动效果。
- 本地模型批量识别；低把握、模型分歧、重大疑似异常转人工。云端调用集中在疑难项，保留原图和复核结果。
- 展示点估计、95% 区间、独立豆数、待复核数和检测范围。待复核样本不能默默当正常，也不能删掉改变分母。
- 即使抽样完美，分类误差仍会扭曲批次率。举例：真实瑕疵率 1%、灵敏度95%、特异度98%，预期模型阳性率是0.95×0.01+0.02×0.99=2.93%。不能把该模型阳性率直接报告成真实瑕疵率。

参赛定位建议：为中小烘焙商提供逐颗可追溯、可复核、明确不确定性的生豆可见瑕疵抽检。TasterMatrix 可作为批次与检测记录入口，首版不把完整SCA分级或所有内在缺陷诊断作为已经达成的能力。
