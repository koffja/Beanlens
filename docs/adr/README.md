## ADR 0005：v1 简化——无批次、无证据图、纯数字计数、屏显极简
**日期**：2026-10-23  
**状态**：已接受  
**摘要**：v1 一律散测（不做批次关联）、无证据图（省裁图+上传管线）、扫描中纯数字显示（无实时预览）、配网用软键盘、配对码只做 6 位数字。批次/证据图/二维码/softAP 全部延后到 P2。

## ADR 0004：会话状态机、放弃机制、400 拒收重报规则
**日期**：2026-10-23  
**状态**：已接受  
**摘要**：状态机 7 态（待机/扫描中/结果待确认/排队待传/上传中/已入库/已放弃）；结果页不能补豆（只能新会话）；有「放弃」按钮（二次确认+本地留档7天）；400 拒收后可改数据但复用同一 `operation_id`；断电恢复为「未完成」但不可上报；checkpoint 每 30 颗或 5 秒。

## ADR 0003：C6 作网络桥，交互统一在 BOX 屏
**日期**：2026-10-23  
**状态**：已接受  
**摘要**：K230D BOX 自身无 WiFi，通过 UART 与 ESP32-C6 桥通信；C6 当哑管道（WiFi + HTTPS）；配网交互统一在 BOX 的 640×480 触屏（软键盘输入 SSID+密码）；C6 的 1.47 寸屏只显示网络状态灯；未绑定时允许扫描（匿名会话，绑定后自动上传）。

## ADR 0002：双摄配对用时间戳+轨迹,豆粒总数不依赖模型
**日期**：2026-10-23  
**状态**：已接受  
**摘要**：双摄非硬同步，配对靠时间戳差 ≤ `ΔT`（初值 2 帧间隔）+ track 一对一消费；采集方案：低分辨率常开前景判断 + 触发 3 帧连拍；豆粒总数 = 配对成功数 + 配对不明数，不依赖 16 类模型；数豆手段分阶段（v1 简单前景+轮廓，v2 轻量二类检测模型）。

## ADR 0001：瑕疵枚举以 SCA 物理性评估表为权威，设备端只出预览计点
**日期**：2026-10-23  
**状态**：已接受；**当量表待用户对照 SCA 原截图逐行核对**（2026-10-23 晚补充：撰写后续文档时的会话无法读取该截图，表内数字未能二次验证，核对前不得写入固件常量或平台规则配置）  
**摘要**：枚举与当量以 SCA 物理性评估表（350g 样品版）原文为唯一权威（类别一 6 项、类别二 10 项）；平台侧枚举需修正：`fungus` 改为类别一、`elephant_ear` 移除或并入 `shell`、`immature` 与 `withered` 拆为两键；设备端计点仅作预览（屏显标"临时规则"角标），落库计点由平台按自己的规则版本重算并签章；设备上报体不含任何点值。

- 新增 ADR 时按模板写（见 `~/.workbuddy/skills/domain-modeling/ADR-FORMAT.md`），提 PR 前补进本索引。
