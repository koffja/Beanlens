# 双板固件准备与分阶段验收

状态：2026-10-12，开发入口与规则已配置；以下实机步骤尚未完成。每次验收记录日期、板型、固件/SDK、接线、输入、预期、实际结果和证据路径，禁止只填“通过”。

## 阶段 0：确定版本，不先接执行器

1. 对照 `config/hardware-baseline.json` 与实物，确认 BOX、C6 非 Touch、相机线序和电源口。
2. 记录 BOX 当前运行的 CanMV/nncase 版本、TF 内容和可恢复镜像。资料盘里已有 v1.2/v1.3、nncase 2.9.0 文件，不代表已烧录。
3. 取得 C6 官方例程，核对其 ESP-IDF、LCD 驱动和 LVGL 版本；再记录 SDK 基线和建立最小构建工程。
4. 训练 `.venv` 保持不变。若转换模型需要不同 Python/nncase，新建独立转换环境。
5. 电源先空载调至 5.0V 与 6.0V并标识；工业信号通过已核对电平接口。首次只给板卡供电。

完成证据：版本记录、镜像校验值、上电电压记录、引脚复核表。此阶段不要求料斗或生豆。

## 阶段 1：两块板分别显示与通信

- BOX 使用匹配官方例程验证主屏与 UART1；C6 验证小屏与计划 UART 引脚。
- 先不接舵机，用模拟限位与 STOP 输入验证状态。两板 3.3V UART 交叉 TX/RX，共地，不连接 PH2.0 的 5V线。
- 按协议草案测试分包、粘包、超长行、坏消息、重复序号、旧会话、断线和重启。主机测试与真实串口测试分开记录。

完成证据：双方收发日志，任何失败都不会产生开闸许可；日志不能混入协议串口。

## 阶段 2：控制端与空载闸门

- 先手推闸片顺畅，再用独立 6V 接空载 MG996R，小角度确认方向与限位。
- 标定开/关终点和动作时限，确认 STOP、失联、超时及限位矛盾会撤销送料，故障不持续顶住。
- 用户要求槽内关闸与缓关，见[机械与轨迹补充](../hardware/GATE-ENCLOSED-SLOW-CLOSE-20261012.md)。空载先验证逐步目标轨迹；带豆2–4秒仅作实验起点，关闭超时/授权时限/尾流收尾重新标定。低速不等于限力，两端限位不能识别全部中间卡豆，需另验检测与卸力。
- 记录供电峰值、主板是否复位与温升。无复位不等于瞬态完全合格。
- 盒到位尚无自动传感器；首版仍要求人工确认收豆盒已放回。

完成证据：空载动作和异常测试，随后才允许小量单槽生豆。没有硬件急停与失电自闭的证据，不使用这些宣传表述。

### 光电台架核验

默认候选Adafruit 2167：5V供电，接收信号10kΩ上拉3.3V、经1kΩ至拟定GPIO20。先不连GPIO测遮挡/无遮挡电压，合格后重复遮挡并与相机比较，检查红外亮点和多槽合并。B3F-20C1接线资料未核时不得按工业NPN图接线。光电只作经过提示，不能独立计数或判空。[接线说明](../hardware/BEAM-SENSOR-20261012.md)。

## 阶段 3：成像与模型

- 单摄先用静态标尺、灰参考和生豆调焦，验证视宽、两端清晰度、短曝光与固定白平衡。
- 6000K/Ra98 为两选一的工程优先方案，实际灯型号、剪切间距和功率仍待确认。
- 接双摄记录实际同时帧率、时间戳、裁图与内存；不把“两路接口”当作硬同步。
- 从已有训练 run 选择权重，记录标签映射与预处理；导出 ONNX、转换 kmodel 后，用同一组完整豆体图分别比较主机与 KPU 输出。
- INT8 校准须包含实际装置的正常与异常样本；公开图集上的结果不能直接当成设备表现。

完成证据：静态和落豆图片、双摄吞吐/内存、转换日志与模型校验值、主机/KPU差异。若转换失败先处理兼容性，不直接换框架或升级全部环境。

## 阶段 4：称重独立验收

具体机械、电气与0.1g验收方法见 V4.4 手册第05A章和第12图，不在此重复。

先确定传感器实际型号、激励与接口。1kg方案仍是目标；用户HJ-AZ4-3kg/103元候选未证明数字接口、包含支架或±0.1g；旧L6J1推荐5–10V与当前3V激励不匹配，见[采购纠错](../hardware/PROCUREMENT-AUDIT-20261012.md)。称重不合格不阻断单独验证视觉，但不得伪装成自动质量结果。

## 阶段 5：单槽到五槽、离线到联网

- 单槽测试满斗/半斗/尾料、架桥、贴连、碎片残留和拒判；随后扩展三槽、五槽。
- 每批比较人工已知颗数、可靠分类数、拒判数、重复数与缺失数。断线、过载、相机或存储异常必须生成未完成记录。
- 先本地完成批次和证据，再联调 C6 有界网络队列；重试不能制造重复批次。
- 参赛演示先做到有图、有据、能复核，不把杯测、完整SCA分级或工业色选能力加入未验证承诺。
