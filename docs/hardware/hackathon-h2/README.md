## 为什么这样改漏斗

| 方案 | 拍照条件 | 比赛取舍 |
|---|---|---|
| 上下相机＋透明托片（本版） | 豆停稳，两次拍摄共享同一颗豆 | 机械改动小，不抓落豆瞬间；要处理玻璃反光、豆屑和接触区遮挡 |
| 两侧相机＋窄支承/夹持 | 可静拍，但豆姿态、夹持点影响可见面 | 无玻璃透拍；需要额外定位，不能承诺正反大面都看清 |
| 开放落豆窗＋两侧相机 | 自由落体连续取帧 | 无托片遮挡；增加短曝光/照明、时间窗、配对、漏拍与重拍难度 |

本版保留已确认的静拍流程。将原来的不透明PP槽底替换为可抽出的玻璃片，PP只做侧壁、边托和底座框。上相机垂直向下，下相机垂直向上透过玻璃。相机不用在豆滑落时追拍，也不增加翻豆机构。

**料斗分成三段，不包成一个封闭斗：**

1. 前端短导豆口，45mm宽入口收至25.8mm，人工一次放一颗，不承储豆载荷。
2. 中段玻璃拍摄槽，底下必须通光。两侧PP支承与玻璃边托固定；挡片仍从侧面摆开。
3. 出口后方独立接豆斜槽，把豆引向Y165，再落进同一杯。下相机前方另有防撞挡板；不能把相机放在豆的直接落点。

## 怎样先拼样机

1. 先买玻璃实物并量宽、长、厚。拿一颗豆、两相机和常亮灯做台面样：上面能拍清、下面透玻璃也能拍清后再裁大板。下视图若被反光覆盖或近焦失败，先调灯角、遮光与镜头；无法解决则保留H1，不用动画预设图冒充通过。
2. 工作板扩孔，底座开窗，暂用可拆支架装侧壁与边托。先纸样核玻璃、挡片和两镜头视线；玻璃先拿开，再练PP焊缝，不在玻璃旁直接热风焊。
3. 固定上下相机，先不装舵机挡片，用标尺检查ROI、豆粒原始像素和对焦。支架承重，排线留弯曲余量，不能穿过挡片扫掠区。
4. 放回玻璃，仅轻夹边缘；装一只舵臂与挡片，舵机6V断开先手动确认全行程。关限位放舵机侧，避开拍摄带。连接角片防转孔位按实物处理。
5. 装后接豆斜槽、防撞板和杯，手动放豆观察路径。下相机用纸板占位先试，确认豆不撞纸板后才装镜头。再空载通电标定限位与舵机脉宽，最后逐颗联调。

## 运行与失败处理

两摄先连续预览；启动不自动开闸。关位明确、两路图像可用后，人工放一颗并按KEY0。停稳后依次取A上视和B透托片图，两图绑定同一cycle_id，检查是否新帧、对焦/曝光可用，再推理/保存。无需宣称硬件同步；帧新鲜度阈值尚待标定。

任何一路缺图、模糊或低置信，整颗记拒判/待复核，不算正常。任一有效视图疑似，整颗标疑似；两路均有效且满足正常门槛才报正常。两张图只计一颗豆，不能报告两摄覆盖全部表面。图像、模型或保存失败时不自动放走；人工确认/处理后再操作。

结果与两图保存完成，开闸放豆；通过空槽图像＋人工可见确认后缓关，关位确认再允许下一颗。限位矛盾、卡豆/超时先停止新增动作，不持续加力；KEY1是软件停止，非硬急停，断电不保证自动关闸。H2动画中的结果、曝光提示和时长都是预设演示。

## 电源与接线变化

- 主电源YU2405 24V5A保留；BOX仍由TPS5450候选成品板供5V，MG996R仍独立好盈UBEC5A设6V。H1缓冲/限位/按键引脚原样保留，不借用C6引脚。
- 两只GC2093分别接BOX的CSI1/CSI2兼容口，排线方向按实物核。CSI供电来自板卡，不能给摄像头接24V/6V。
- 灯从2段增至4段，按每段100有效长/≤20W每米起算8W。持续预算5×3/0.8＋6×3/0.8＋8=49.25W；舵机短峰按5A为64.25W。只是预算，双摄主板5V电流/纹波/温升、灯亮度和保险仍须实测，不因此宣布供电验收。
- BOX官方说明确有两个GC2093 CSI接口；具体CanMV版本、Sensor(id)映射、双摄＋显示＋KPU内存尚未在本机验证。先双路低分辨率预览确认，再按需要验证原分辨率裁图与内存上限，不套别家K230例程的引脚或镜像。
