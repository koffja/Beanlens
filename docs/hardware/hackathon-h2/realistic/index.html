为什么下面必须留空？

上相机直接拍上面，下相机透过玻璃拍另一面。PP只托玻璃边缘；后接豆斜槽把豆引到镜头后方。两张图配成一颗豆，仍只用一只舵臂。

外形重建 ≠ 原厂CAD。透明托片光学质量、两摄近焦/像素密度、净空与触发位置待实配；分类与时间为预设。

双摄怎样保留比赛简化？

上下两只GC2093、可拆透明托片、短PP导豆口、后接豆斜槽、下摄防撞板，及黑框/木平台、BOX、舵机与同一收豆杯。上下各两条常亮灯。

光路视图暂隐木台与遮光片；整机模式恢复木台。展示的分类为预设结果；自动播放代演人工投豆与按KEY0。真实机器须先确认关位，再允许投豆。
