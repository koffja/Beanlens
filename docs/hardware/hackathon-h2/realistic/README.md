# H2 双摄拟真教学动画

打开上级 `beanlens-realistic-h2.html`，单文件离线运行。默认“透视侧壁”仅是教学剖视，实物侧壁仍PP；切换整机或取消该项即可恢复实物外观。双摄光路线以蓝/橙表示，不是实际可见激光。

H1外形基础文件以独立副本放在本目录；不修改H1。H2新增可拆玻璃托片、上下两相机、短导豆口、后接豆斜槽、下相机防撞板和支架，几何与BOM见上级README及design-h2.json。

构建顺序：`build_h2.py`生成结构/BOM/基线；`prepare_view.py`从H1教学页面派生H2界面；`build_view.py`内嵌Three.js与代码，得到离线HTML。运行`check_view.cjs`做本地浏览器检查与73帧导出，`export_gif.py`组合为GIF。Three.js 0.160.1固定本地版本，MIT许可随附，不发网络请求。

页面预置A上视、B透托片下视和分类结果。相机不随挡片动；豆保持静止时依次拍A/B，然后才开闸；两图只计一颗。教学轨迹没有接触动力学求解，不能替代实豆防撞/落豆验证。

射线检查只审查两条中心线是否被模型中的不透明零件挡住，不证明整幅视场、折射、反光、成像质量或PCB/排线实际净空。相机PCB与支架均非厂家CAD，尚未放行加工。原厂来源与验收操作见上级README。
