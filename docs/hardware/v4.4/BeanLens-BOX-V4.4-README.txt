关键结构：正面K230D BOX贴装，主板位于箱内独立维护仓；C6小屏放右侧。上部木壳四壁垂直，内部四片PP收口；支撑用左右耳板，不堵出豆口。五槽送料、前后双摄、下部开放取豆仓和独立称重台。
关键电源：外置24V/4A稳压适配器优先；四段24V灯带并联；独立24→5V支路给两主板，独立24→6V支路给MG996R。3.3V小负载先用C6板载稳压，核对余量。相机通过兼容CSI接口供电，不另接5V。
NPN对射器用支持24V输入、3.3V输出侧的光耦接口。非隔离降压共地时，光耦不构成整机电源隔离。B2403S-1WR3是1W、3.3V、非稳压隔离电源，后接AMS1117-3.3没有压差余量，不采用此组合。
称重目标：总承载1kg，净样品通常0～500g，分度0.1g；静态误差±0.1g为待验收目标，尚未验证。去皮不恢复量程。3kg候选达到同样目标更难，不能只凭小数位确认。
海洋板可以作外底板，传感器固定端优先连接到2020底梁上的刚性金属底座。原厂匹配支架若包含所需受力组件，适合初学者；仅有安装角码不代表完整称台。
