# 对射器的用途、型号与接线修订

更新：2026-10-17，V4.11 MVP。**当前主选DFRobot SEN0503（50cm对射，一组收发头）**；原Adafruit 2167与山大斯B3F-20C1只保留历史/有条件备选，不重复采购。未上板或带豆验收。

## 它在本机做什么

发射头与接收头面对面，豆子遮断光束时给控制板“有东西经过”的提示。相机仍连续采集；光电可辅助记录有流/无流、残流和异常。

五槽共用一束光，多豆同时或紧挨着经过会合并成一次遮挡，小豆、偏移和间隙可能漏检。它不负责逐豆计数、触发每颗豆的唯一照片或证明已经排空；持续遮挡也可能是积尘或失准。颗数依靠图像跟踪与去重。首阶段可先不装光电，验证连续成像与送料。

## SEN0503规格与采购

[DFRobot原厂规格](https://www.dfrobot.com/product-2388.html)：DC3–5V，**50cm @5V，20cm @3.3V**，工作电流25mA、响应约2ms，NPN常开输出，头部20×10×9mm、线长250mm，适合室内、非防水。本机按5V供电。标称距离不保证每颗豆都检出。

[国内官方商城](https://www.dfrobot.com.cn/goods-3274.html)型号SEN0503，2026-10-17页面参考15元/对，非用户成交价、不含运费。购买一组收发头，不是两组；核对是否附支架，不默认有螺钉。原厂100mA是输出能力，不能作为GPIO灌电流使用。

## 接线：5V供电，信号拟定上拉3.3V

原厂仅给出NPN常开，未给完整内部上拉电路；以下是待台架核实的接口。**不要照搬原2167的“遮挡LOW”结论**；基线有效电平暂为null，测后填写。

| 对象 | 接到哪里 | 说明 |
|---|---|---|
| 发射头红线、接收头红线 | TB-B 1，5V逻辑支路 | 不接24V或舵机6V |
| 两头黑线 | TB-B 2，5V返回 | 与C6信号地共参考；不让舵机电流走C6 |
| 接收头白线 | 信号节点A | 线色按所购资料复核 |
| A节点 | 经10kΩ到C6 3.3V | 只有信号上拉用3.3V，红线仍5V |
| A节点 | 经1kΩ到拟定GPIO20 | 初测先断开GPIO；1k不是5V转3.3V电路 |

[六页接线/结构图，第6页逐线连接](revision-v4.11/beanlens-hopper-gate-v4.11.html#page6)。GPIO20是拟定分配，首次接线核对板卡与[硬件基线](../../config/hardware-baseline.json)。

1. 暂不接GPIO20，接5V、公共地、10k到3.3V。用万用表测A对公共地。
2. 对准光束，交替无遮挡/完全遮挡，分别记录电压与哪一状态为低。台架高≥2.5V、低≤0.8V作为起试检查，同时确认没有超过3.3V的输出；逻辑门限最终按C6资料核对。
3. 若出现约5V、浮动或两状态不明确，保持GPIO断开，核查内部上拉/输出和线序。不能靠1k串阻解决；确认具体电路后另配电平转换。
4. 两状态电压合适后断电接GPIO20，再开机重复遮挡并记录有效电平；未记录前不在固件硬编码遮挡LOW/HIGH。
5. 重复对准、线缆摆动与实际豆样检查；对比对射开启/关闭的相机图像，观察红外亮点、误提示和失准。失败时先调光轴和遮光，不用软件滤波掩盖接线错误。

安装仍从槽盒出口下约3mm、光束Z277起试；头放两侧，不侵入豆路。20×10×9是外形，未确认哪条轴沿X/Y/Z、光孔偏置及安装孔距，不能仅用9mm厚度判定避开PP侧封片或底脚。PH04两个可调小支架先按实物定位，不购买M12工业支架替代。

## 山大斯的有条件备选

用户曾提供B3F-20C1，确切原厂接线图仍缺。取得标签后，只有确认24V NPN低端输出才可评估I02–I07的LTV-817小板：24V→4.7kΩ/0.5W→光耦LED→传感器低端输出；LED反并联1N4148。光耦输出集电极经4.7kΩ上拉C6 3.3V，发射极接C6地，端子/保护极性/漏电另验。PNP、推挽或不同电压不能套用。共地非隔离降压下不能称整机隔离。

当前采购以[114项V4.11采购表](procurement-v4.11/beanlens-procurement-v4.11.html)为准；不购买工业转换备件作为SEN0503必需件。
