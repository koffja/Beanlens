# 对射器的用途、型号与接线修订

2026-10-12。采购建议，尚未上板或带豆验收。用户提供原型号：**山大斯 B3F-20C1**，保持此写法；尚未取得该确切型号的原厂接线图，不能凭名称判断NPN、PNP、工作电压或发光类型。

## 它在本机做什么

发射头与接收头面对面，豆子遮断光束时，控制板收到“这里有东西经过”的提示。相机仍然连续采集，光电可辅助记录有流/无流时段、残流和异常排查。

五槽共用一束光，几颗豆同时或紧挨着经过会合并成一次遮挡；小豆、偏移、间隙也会造成漏检。因此它**不负责逐豆计数、触发每颗豆的唯一照片或证明已经排空**。持续遮挡也可能是积尘、失准，不能单独判堵。颗数仍要靠图像跟踪与去重。首阶段可先不装光电，验证连续成像与送料。

## 建议改用 Adafruit 2167，3mm红外对射一对

[原厂产品页](https://www.adafruit.com/product/2167)给出：供电3.3–5.5V、标称距离25cm、响应小于2ms、发射角约10°、单头约20×10×8mm，线长约230mm；输出为开集电极。该规格足以作为本机约110mm宽豆帘的试样候选，实际安装距离与灵敏度仍需验。

它更适合初样的原因是低压供电，开集电极信号可以单独上拉到3.3V，省去24V输入光耦。**推荐5V给收发头供电，信号只上拉到3.3V**；5V供电不等于允许5V信号进入C6。

| 对象 | 接到哪里 | 预期结果 |
|---|---|---|
| 发射头红线、接收头红线 | 独立5V逻辑支路 | 不接24V，不接舵机6V |
| 两头黑线 | 公共GND | 与C6信号地共地 |
| 接收头白线 | 先接10kΩ电阻的一端；电阻另一端接C6 3.3V | 只用这一处3.3V上拉；不同于红线5V |
| 白线信号节点 | 经1kΩ串联电阻接拟定GPIO20 | 串联电阻不负责把5V降到3.3V |

[原厂示例](https://learn.adafruit.com/ir-breakbeam-sensors/arduino)中遮挡读LOW、无遮挡读HIGH。示例的5V Arduino上拉接法不能原样移植到C6。GPIO20是项目拟定分配，首次接线仍核对基线与板卡。

先不连GPIO，用万用表测白线节点：无遮挡接近3.3V、遮挡接近0V。台架起试高≥2.5V、低≤0.8V，再检查重复遮挡和线缆摆动。若输出约5V、反应不稳定或型号是兼容替代品，先断开，检查其输出电路、是否内置5V上拉；不能靠1k串阻解决。线色必须与实际产品资料核对。

安装从槽盒出口下约3mm、成像主视野上方起试；收发头放两侧，不侵入豆路。避开灯带和直射光，先比较对射开启/关闭的相机图像，验证红外是否在豆面或背景产生亮点。25cm、2ms是原厂条件下参数，不保证五槽中每颗豆都能检出。采购用两个可调小支架，不必再买M12工业支架。

## 山大斯能不能保留

可以在取得B3F-20C1标签/接线图后再评估，没必要为了“工业”二字换更复杂的模块。若确认为24V NPN低端输出，才可用采购表I02–I07的LTV-817转换小板：24V→4.7kΩ/0.5W→光耦LED→传感器低端输出，LED反并联1N4148；光耦输出集电极经4.7kΩ上拉C6 3.3V、发射极接C6地。具体端子、反向保护极性与漏电要代焊核验。

这是一组**有条件的备选电路材料**，不是已核合格的成品模块。若是PNP、推挽、其他电压或不同输出逻辑，需重新选接口；不能套此电路。共地非隔离降压下，即使用光耦，也不称整机电源隔离。

型号、支架、电阻与备选光耦均已列入[当前采购表](procurement-v4.5/beanlens-procurement-v4.5.html)。默认采购2167路径，B3F转换件作为备选，避免两套重复购买。
