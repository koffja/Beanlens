## 机架与木板

共享坐标来源是[frame-plan-v4.6.json](../frame-v4.6/frame-plan-v4.6.json)，其内容为V4.7。骨架220×240×460；连续立柱460×4，横梁200×6、180×8，共18根，净4480mm。中框前后180横梁现在位于Y0/220，与柱外面齐；按钮中心改Z273。顶框Z440–460，中框顶324，托耳6，主斗底330/顶440，上口圈顶442。

左、右、后三面延伸到基座，木板在横梁处分块，四角露黑色2020。9块外板均厚6：前/后上176×112各一，左/右上196×112各一，左/右下196×280各一，后中176×58、后下176×197、前中176×58各一。正面下方仍为取盒开口。板边约2mm缝、面内凹约1mm；木板不在外角相互拼接。

料斗木壳外158×158×110，前后158×110×6各一、侧壁146×110×6各一；托耳40×30×6两片。共15块木件，800×600×6一张按图排版；已有600方时改用两张600×600，不重复购买800板。F11面板内角片/背托34用、40购；11mm隔距为试装起点，按角片实际支承面调整。F08只管料斗木壳与托耳，不能沿用旧外覆板穿T螺母的固定图。

## PP料斗与五槽

F04用2mm PP-H：顶口内136方、底口110×30、垂直高110，四片斜面焊合；斜高不是垂直高。上口另加158方口圈，下口用3mm接环接28.7高小过渡斗，渐缩到82×12槽列。模板线表示内表面控制边，须纸样、留修边量并试配坡口，不是最终斜切加工轮廓。

五槽采用上下五窗叠片：PP3下层两片140×18、POM4支承140×30、闸片缝名义2.3、PP3上层两片140×30；五窗均14×12、筋3。不能用四片连续50mm隔板穿过闸片。闸片110×45×2，沿Y移动15；两侧隔距在闸片扫掠区外，厚度按实物调。G13/G20后侧防护仍须对加强梁、滑架和润滑区做全行程纸样，未完成不能带豆电动测试。

## 型材如何订货

已有460×7：四根保留，其余三根各切200+200；400×2各切180+180；补同槽型黑色欧标180mm成品四根。每刀3mm时，原料4740＝净4480＋锯屑30＋余料230。F02角码28用32购，螺钉/T螺母各64，按现有槽口实配。

## 看图与验收

先框架松装校方，再木板角部样件、纸料斗和废料试焊；之后冷却检查料斗、手推闸片、单槽少量豆，最后五槽联调。相机板、镜头、称重件孔位和供电模块外形按实物核，不能用占位块加工。HJ-AZ4-3kg孔距/高度未知，称台Z45只是目标；装得下不证明称重精度。
