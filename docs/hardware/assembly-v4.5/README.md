## 本次补全的布局与BOM

保留220×240×440骨架和18段型材，净长4.40m。明确220梁沿X贯通、200侧梁夹在前后梁间、400柱在上下框之间；两根180相机梁单独装在前后立柱间。

料斗中框顶面采用Z324的布局提案，加6mm托耳后承托木壳底面Z330，木壳顶面Z440。旧约25×30托耳未闭合13mm间隙、木壁与搭接，本图改为40×30×6，两侧搭住20型材并承托木壳，中央豆路仍贯通。托耳与木壳用外侧小角片固定，螺钉头不侵入豆路。

外壳四板净裁切为前/后220×240×6各1、左右240×240×6各1，Z200→440。包覆外尺寸232×252×440，不含脚垫、插头、线缆。底部不封木板，遮光底板下保留约180宽×174高取盒空间，仍须用实际盒子验证抽出路径。

料斗四木壁仍是前后154×110×6各1、左右142×110×6各1，外154方、内142方。四面垂直，收口由PP内衬完成。PP上口140留装配量；木板厚偏离6时，142尺寸与内衬余量需重算。

第03页排版在600×600板内，边缘约3mm，矩形间隔至少3mm。一张可容纳本次10片净裁切件；此为排版提案，按真实板有效面积、锯缝、顺纹、破损与锯切顺序复核，不保证所有加工店都能同样出材。

F02角码由旧24估量补为28使用：上下框16、中框8、相机梁4；购32含4备，M5×8与T螺母各64含备。B13相机支架到型材的安装M5件独立随套核对，未重复计入骨架角码。

新增F08：6mm木面板/托耳需独立M5×12/T螺母/垫片各20（18使用、2备）及料斗小角片/M3件；不是把F02的M5×8直接穿木板。长度仍需对实物槽深、垫片、螺纹啮合复核。

F06明确200×200×2铝板毛坯可排电控160×130、BOX夹持80×60、C6夹持60×35三片。它们是托板尺寸，不是PCB孔距。电控托板经绝缘柱装在后检修板内，低压电源适配器留机外；散热、插头和线束摆放待实物纸样。

当前五槽净宽5×14＋四隔板3＝82，外宽110剩28，本图左右结构区各14（含侧壁与安装翼）。导轨中心距由旧约90起点改画94，以给五槽实体/侧翼留下布局量；这是纸样提案，不是已验公差。

## 尚不能直接加工的部分

- HJ-AZ4-3kg的外形、孔距、输出和组件高度未知；虚框只是预留位置。台面Z45为目标，不能凭虚框制造垫块。
- GC2093 PCB/镜头长度与BOX/C6实际开口未知；工作距离75与光轴Z241.25要靠标尺、调焦和视野验证。
- 闸片/转接板厚度可按毛坯询价；MG996R花键、支架、球头安装堆叠、连杆平面和机械端点孔仍需实物。
- G11图示了前豆路与后舵机避空方向，但未给最终缺口公差；底座不能将140×140整片塞入。100轨的端余量及后摄视锥尤其需要纸样/实测。
- 灯带真实宽、切点、功率、散热槽和对射固定孔待到货；图中的100有效长、14×8铝槽是参考占位。
- 角码、T螺母、托耳和面板受力未经实物承载/振动验收。手推顺滑后才接舵机，不靠硬拉校正机架。
