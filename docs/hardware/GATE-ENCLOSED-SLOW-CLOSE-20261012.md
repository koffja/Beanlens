# 槽内平移滑闸与缓关

日期：2026-10-12。用户明确要求：开关豆路的位置在落豆沟槽内部，避免出口外的闸片扫碰豆子；希望缓关，让闸片有机会进入豆与豆的间隙。以下是设计要求与待验证方案，尚未加工、上板或带豆验收。

## 动画入口

[HTML＋JavaScript离线动画](illustrations/beanlens-gate-motion-20261012.html)：先开闸再缓关；可调0.5–5秒全行程关闸时间，默认3秒，可暂停、手动拖动并分别高亮舵臂、双球头杆、导向滑架。两幅视图同步：俯视讲传动，单槽侧剖面讲挡豆位置。页面没有硬件连接、外部脚本或自动启动动作。

## 结构修正：挡豆位置与外部传动分开

闸片水平穿过后壁窄缝，在五槽内部向前推进；全关时直线前缘进入前壁接收槽，全开时退到后壁之后的封闭退片袋。闸片下方仍有沟槽围挡，之后才是自由落豆出口。不能把工作前缘装在槽底外侧绕轴扫动。

V4.4已有闸面z292、出口z280，名义上相差约12mm，可作为下游围挡高度起点。该高度不是已经证明能防飞豆或消除夹豆的数值；尾豆、豆形、碎片、反弹和相机视野须联合验证。壁缝、接收槽和退片袋需可拆清理，检查碎屑回带；导轨润滑和舵机连杆位于与豆路隔开的后部传动区。

五槽在同一前后位置，净深12mm；名义15mm行程分为12mm豆路＋关闭端1.5mm覆盖＋打开端1.5mm退让。槽内接收槽的实际尺寸、防漏、防卡余隙和后方口袋长度尚未冻结。2mm铝片不能沿用原1.3–1.6mm导槽。横梁及两导轨滑块布置在豆路后方，不能挡住通口。

传动采用[配件建议](GATE-PARTS-20261012.md)的16mm舵臂孔、60mm球心距M4双球头杆。舵轴竖直，连杆在水平面摆动，中心球头经连接耳连接120×30×3mm转接板/后横梁组合。左右导轨约束闸片平移，球头本身不提供同步或防偏转。真实舵机与闸片的旧23mm高差，需要支架/连接耳重做共面或三维受力复核，动画的共面理想机构不是旧支架的直接装配证明。

动画使用居中曲柄滑块：`A=(r cosθ, r sinθ)`，`B=(0, r sinθ+sqrt(L²−r²cos²θ))`，r=16、L=60mm，θ=±asin(15/32)≈±27.953°。端点行程15mm；中间按闸片位移反解θ，因此连杆球心距恒定。相对角度不是PWM命令角。动画不仿真豆体碰撞、真实受力或流量，五槽几何同步不代表首豆同时下落。

## 缓关可以实现，但不能当作限力

MG996R没有独立的“速度线”；控制板通过逐步改变目标脉宽放慢位置指令。拟定保持50Hz周期、每20ms更新轨迹目标；保持独立6V供电。不通过降低PWM频率或电压调速。实际兼容件的脉宽端点、死区、3.3V信号门槛、负载跟随性和温升尚待测量。

开闸与关闸分别设时间。动画开闸全程1秒、关闸默认全程3秒；2–4秒仅作为带豆实验起点。动画提供理想闸片匀速，以及轻启后末段减速；曲柄非线性意味着等角度增量不等于闸片严格匀速。中途启动按剩余行程缩短时间，本次动作使用启动时设置；这只是教学界面的规则，没有写入产品固件。

缓关有利于降低冲击，可能增加豆体重新排列的机会，但不能保证自动寻找豆缝。MG996R没有向C6提供实际闸片位置、力或卡豆信号；慢目标仍可能让它持续施力。齿隙、静摩擦和死区也可能使低速动作出现小跳。前缘应平直、钝边、去毛刺，不制成锐利刀口硬剪。

实际系统仍需动作超时、滑架端点限位及经验证的阻力/位移检测或机械让位。两端限位不能识别所有中间卡豆。收到异常应撤销送料许可、停止继续推进并记录未完成；不能把停止PWM当作立即卸力，也不能假设失电自闭。断供、有限退让或机械卸力须分别实测后确定。动画的“模拟收到卡豆信号”是人工注入信号，清除后保持原位置，不自动续动。

上电位置未知时，逐步给目标也不能直接保证首次动作缓慢；不得启动自动开闸，先制定端点/位置确认和复位流程。关闸变慢后，关闭超时、授权租约/通信时限、尾流排空与批次收尾必须重新标定；原120ms/500ms等示例不能直接作为新的关闭预算。

## 首样验证

1. 无舵机，手推全宽闸片；确认五槽通口对齐、导向不偏转、前缘全程在封闭槽盒/退片袋内，接收槽不顶死，清洁可达。
2. 独立6V空载标定端点和PWM轨迹，比较1/2/3/4秒关闭，记录实际位移、抖动、到位时间、电流和温升。确认STOP、断线、复位和超时行为；不直接带豆找端点。
3. 单槽少量豆后扩至五槽；空斗/半斗/满斗最多1kg装豆，记录夹豆、破损、残流、槽外飞豆、退片袋回带和五槽同步。发现夹豆先停机排障，不持续加力。
4. 关闸后仍可能有围挡内尾豆落下，批次结束需排空、视觉收尾和称重稳定确认；机械关闭不等于相机可以立即停止采集。

- [TowerPro MG996R](https://towerpro.com.tw/product/mg996r/)：原厂规格仅作参考，不证明用户兼容件在本机构中的低速、带载和夹豆性能。
- [Espressif ESP32-C6 LEDC官方资料](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c6/api-reference/peripherals/ledc.html)：硬件PWM与占空比更新能力。未据此选定/升级项目ESP-IDF；轨迹与故障处理需要产品代码另行实现。
