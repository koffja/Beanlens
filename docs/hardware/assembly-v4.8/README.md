## 与V4.7的区别

取消PP外侧木斗和木托耳H01–H06，保留三面木外壳与黑色2020。PP3顶法兰176×196由顶框四金属托片支承，法兰底440/顶443。托片用25×25×2角铝裁宽20、竖外脚22、横外脚14；PP支点底边2×2局部倒角避根部圆角，先实配。不能靠木面板或压迫屏幕来定位料斗。

主斗内口136方/下110×30/高110不变。2mm法向板厚对应外上140.027837×140.440088，外下114.027837×34.440088；四角对称斜接离直切43.539939°。外焊筋法向3mm作为空间上限，水平预留4mm；这不是已验证的焊缝强度指标。V4.7内面模板不再当成品裁切线。

双法兰146×66各PP3，1mm硅胶名义压0.8，合计6.8；小斗高改24.9，配五窗/闸缝18.3，共50，保持槽底280/主斗底330。焊接变形和密封压缩必须实测，不能靠硬拧拉到位。几何/STL不含热收缩补偿。

## 两块屏幕

第08页拆清：BOX整机与内置2.4主屏、外压框、后托框、四角软垫夹片；C6非Touch整机与内置1.47侧屏、外遮边框、PP绝缘后框。屏幕均随板卡，不另买LCD，不拆C6屏幕。BOX原壳无已确认通用安装孔，采用夹壳；C6用M2参考13.08×32，原图2.5H，基准/牙深先核。

第09页计算各服务腔最不利高度处：主屏80×40×64腔最高402，扣PP实料与水平4焊筋储备后17.09mm；侧屏25×85×47腔最高385，净10.49mm。它们是设计边界，插头、排针与线缆必须实际放得下才成立。BOX主要外形64.3×47.6×15.4；C6板20.32×36.37、包深7.6，均不含全部突出物。原厂来源在制作指南。

骨架尺寸220×240×460，外部侧压框到X221、前按钮到Y−2；脚套、线缆等另留量。双屏服务腔不等于散热或天线已验收。

## 材料与剩余条件

型材18根：460×4、200×6、180×8，4480mm；现有460×7/400×2，仍补同槽型黑色180四根。木板只9片，600×600×6一张。PP2 A3两张，PP3 400方一张、黑PP2 160×100一片，两屏外框共板避免重复采购。

第10页列出仍需实物确认的耳板连接/共面高度、后退片罩、称重组件孔高、光学近焦/视锥、模块外形与线束/散热。G09角梁已独立画；G10仍安装占位，G20仍未冻结防护接口。完成这些纸样和手推验收前不带豆电动联调。主斗约1.15L，不保证一次装1kg；承重/蠕变/称重精度均未验收。

## 重建与检查

共享机械数据为[design-v4.8.json](design-v4.8.json)。先生成采购表，再运行build_assembly.py、../fabrication-v4.8/build_fabrication.py，最后export_checks.cjs导出PNG/PDF和浏览器记录。使用项目既定rtk前缀与Bundled Python/Node，不改训练环境。PDF需逐页渲染目视检查后，用含pypdf的Python运行validate_design.py。

[浏览器记录](browser-check-20261016.json)、[几何/实体/PDF记录](validation-20261016.json)仅证明列出的文档检查，不代表实物通过。旧路径已加历史提示；用户原Excel和厂商资料未覆盖。
