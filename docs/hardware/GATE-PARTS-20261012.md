## 本次输入与推荐组合

用户补充：料斗最多装1kg生豆。按闸门可能承受全部约9.81N竖向静载考虑，不把料斗壁的分担当作必要前提。料斗/槽盒本体必须独立固定，不能一起压在闸片上。此处1kg是装豆量；没有据此改变原称重系统的1kg毛载荷、净0–500g目标。

推荐样机：一个MG996R → 25齿铝舵臂的16mm半径孔 → M4双球头短拉杆（约60mm球心距） → 居中连接耳 → 120×30×3mm滑架转接板＋110mm后角铝加强梁 → 2mm铝闸片。两侧直线导向维持平移，竖向重量由固定支承/导向传至机架。球头不负责左右同步。

## 拉杆长度和运动匹配

采用当前goBILDA球头示意图的入口至球心h=24.4mm，牙条长a=30mm，两端各旋入e，则球心距：

`L = 2h + a − 2e`。

L=60mm时，每端约旋入9.4mm，小于公开13mm螺纹深度；中间露出的牙条约11.2mm，可容纳两只普通M4并紧螺母。约56–62mm可作为初调范围，但必须逐端确认有效啮合、不顶底和螺母占位。整根总外形长约74mm，不能把球心距、球头总长和牙条长度混用。

原厂图与标题存在长度差异，最终应根据收到的球头重新量h并计算。不要买“60mm牙条”来代替“60mm组装球心距”；否则连杆会明显过长。

采用16mm曲柄半径后，原±37°起点改为相对横向基准约±28°，理想共面居中机构行程：`2×16×sin28°≈15.02mm`。对于60mm连杆，整个行程无须接近共线死点。实际PWM端点仍用滑架限位标定，不能把±28°直接当舵机命令角。

杆件无需盲目加粗：钢M4短牙条适合这套小型机构的样机配置，中间自由段很短；其强度、螺纹、球头间隙和固定方式一起决定可靠性。若偏斜/摩擦造成推力过大，先处理导向与夹豆，不靠更粗牙条或更强舵机硬顶。

希望直接购买成套可调杆，可按以下规格询价：**双金属球头、杆端M4×0.7、球孔φ4、球心距约60mm且可调、带并紧螺母**。若选φ6mm铝合金主体＋M4端螺纹，也可作为备选，但须供应商提供完整球心距范围和螺纹啮合图；本次未核验某个成套国产SKU的载荷/间隙，不虚构型号。

工业备选为 **THK NHS4T**两只：M4×0.7内螺纹、φ4球孔、自润滑衬层；官方入口到球心24mm、整体长31mm。采用它时重新计算牙条长度和球心距，不沿用goBILDA的24.4mm。THK尺寸表给静径向载荷2250N，但这不是整套滑闸可用推力或舵机承载许可。

## 铝闸片是否适合1kg

建议2mm6061-T6作为样机起点，原因是刚度比原0.8–1.0mm薄POM更容易控制。厚度不能直接塞进原1.3–1.6mm导槽。若仍用POM槽，槽高先按**实测片厚＋总余隙0.2–0.4mm**试做，横向定位间隙另调；这不是最终验收公差。标准导轨方案也需设置防抬/封口余隙，避免把闸片刚性夹在两套约束之间。

用铝板作全宽简支梁粗算（跨度110mm、有效梁宽45mm、厚2mm、E=70GPa、总静载9.81N）：均布载荷挠度约0.081mm；以梁宽方向已分配的跨中集中载荷计算约0.130mm、弯曲应力约9.0MPa。板坯质量约26.7g。计算采用thyssenkrupp的材料参考数据，T6板材强度级别远高于该简化应力。

上述模型只说明全局弯曲的量级，**不是局部豆体点接触、边缘悬臂、螺孔、加工翘曲、安装应力或实物承重验收**。实际增加与槽壁对齐的下支承，可以减少悬空跨度；承重还受支承框、机架和固定件限制。3mm板不作为默认，先避免增加闸口台阶和改造空间。

表面要求：去毛刺、平直、无掉屑，滑动接触采用可拆POM支承；不让铝对铝干磨。可向加工商询问合适的清洁/表面处理，不用“铝合金”或“阳极氧化”名称自动宣称具体成品符合食品接触要求。

## 舵机适配与首样验证

1. 量用户MG996R输出花键并与所购25T舵臂对照，先不通电试装；保留与实际舵机匹配的中心固定螺钉。禁止套用其他舵机的中心螺钉长度或锁紧扭矩。
2. 将两轨固定在共同底座，装横梁/闸片，不接舵机。满行程手推不应卡滞；第二轨尚可调整时，让滑架自己找平行位置，再逐步锁紧。封闭/半开/全开分别量左右前缘差值。
3. 先空载，再0.25/0.5/1.0kg分级加载；载荷施加在实际豆路范围，检查挠曲、滑动阻力、封口和残流。用拉力计沿实际推拉方向量启动力和运动阻力。
4. 装60mm球心距短杆，检查全行程球头与舵臂、横梁、螺钉无干涉。独立6V供电，小角度标定，记录动作时间、电流和温升。
5. 原厂MG996R的6V堵转扭矩11kgf·cm不是连续工作扭矩，也不是用户兼容件能力证明。竖向重力9.81N不是所需水平驱动力；实际还包括支承摩擦、导向阻力与豆体挤压。仅凭1kg豆量不能宣布舵机已足够。卡豆时停机排障，不持续硬关。

纸样必须包含两套100mm导轨、约74mm拉杆总包络、舵机壳体与全行程扫掠，检查原后摄视锥；当前不冻结舵机支架高度和最终加工孔位。
