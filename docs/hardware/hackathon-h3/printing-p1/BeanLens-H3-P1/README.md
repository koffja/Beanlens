# H3-P1：上漏斗／下接豆斗的3D打印包

2026-10-22。按H3单槽、顶入豆、水平双摄的尺寸制作；用户打印平台220×220mm或更大。三件主零件都能单独放入180mm平台，220mm平台有充足摆放余量。本包为**首次试制版**，不是实机验收版；不含打印机专用G-code。

先打开[预览与安装尺寸](preview.html)。全部文件均为毫米，切片时**100%尺寸，不自动缩放**。STL用于切片，3MF是带毫米单位的通用模型，不含机型／耗材预设；STEP用于CAD修改，真正可调参数源文件是`build_print_models.py`＋`parameters.json`。[CadQuery原厂格式说明](https://cadquery.readthedocs.io/en/stable/importexport.html)

**主件总共打印3件**。上漏斗分成两件，是为了让大斗壁及接座各有平整落床面，减少长距离悬空支撑，也方便拆洗；不是把四面斗壁分别打印再粘起来。原H3的PP顶环、闸盒上下盖／两侧垫条、下短管、铝闸片继续使用。**PETG打印件不与PP热风焊接**；这里靠螺栓和插接固定。

`assembly-reference-only.step`把三件打印件摆在H3安装坐标中，供核对位置，**不要把整个装配文件直接送去打印**。单件STEP与STL都已按打印方向摆好。

## 建议先打两个小试片

先打印[公头试片](fit-tests/test-male-mm.stl)与[母座试片](fit-tests/test-socket-mm.stl)各1个。它们复制上漏斗的实际插接轮廓：公头22.8×18.8，母座23.2×19.2，每侧名义间隙0.2。倒掉毛丝后应可手插、可拔出，不能靠锤敲或螺栓压入。

若卡紧：先排查首层象脚及孔壁毛丝，轻修试片；若仍紧，修改`fit_clearance_each`后重新生成，**不要整件缩放**。若明显晃动，减小该参数后再打试片。母座不靠过盈承担重量，上斗主要固定在顶环上；下端只导向定位。

## 打印方向及切片起点

候选材料选PETG；PLA也可先打接头／装配检查件，整机耐热和长期承载仍需按实际材料验证。PETG的原厂资料也提示其桥接／悬垂表现需留意，因此下斗法兰有意安排外侧支撑，不向豆路里加难拆的支撑。[Prusa PETG说明](https://help.prusa3d.com/article/petg_2059)

| 零件 | 已设置的STL方向 | 支撑处理 |
| --- | --- | --- |
| 上斗身 | **大口法兰贴床、小口朝上**，倒着打印 | 先按不加支撑预览；斜面相对竖直约19–20°。确认切片中壁线连续，豆路内不要自动塞满支撑 |
| 上接座 | **50×85底面贴床、插口朝上** | 先按不加支撑预览；孔贯通，不应出现盖住18×14孔的封顶层 |
| 下接豆斗 | **30×30小口朝下、64×64大口朝上** | 给90×90法兰的悬空底面加**仅从平台生成、只在豆路外侧**的支撑；用支撑涂抹或阻挡器排除内通道 |

0.4mm喷嘴、0.20mm层高、5–6道墙、至少4层顶底可作起点；固定法兰实体区域填充20–30%。最小设计壁厚2.4mm。可加约5mm裙边改善细窄口沿贴床，取下后修掉外缘象脚；温度、速度、风扇和支撑间隙使用耗材／打印机已验证的PETG预设，再按试片调整。**不提供未经该打印机验证的打印时长、耗材重量或热端温度。**先检查切片逐层预览，尤其是下斗法兰和四个安装孔。[Prusa建模与支撑说明](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)

## 安装步骤与孔位

下列是H3整机坐标，X左右、Y前后、Z向上，单位mm；前为小Y。参考框架220×240×460、中心X110/Y120。**先打印试片和实物对孔，再钻现有板材。**

1. **保留原PP3顶环176×196、80×80孔。**上斗104×104×4法兰贴在顶环下面，上表面Z440。顶环新增4个φ3.4孔：X64/156与Y74/166的四种组合。相对顶环左前角X22/Y22，即X42/134、Y52/144。用M3×16、两侧平垫及防松螺母4套夹紧，松装找正后轻紧，不靠螺栓把翘曲件拉平。
2. **接座放在原PP上盖顶面Z329.3。**接座平板3mm厚，新增高度朝上；原闸片324–326与上盖326.3的关系不变。使用原4孔：X90/130、Y105/165。接座左前角是X85/Y95，局部孔坐标为X5/45、Y10/70。接座长边后端到Y180，要朝舵机连杆一侧。原孔若未钻，先对照实物确定再钻。
3. **这里把4根盖板连接螺栓换成M3×20候选。**夹层厚3+2.3+3+接座3=11.3mm，再加平垫／螺母核有效啮合；不能继续默认原M3×16一定够。所有螺纹在18×14豆路外，螺杆端不顶住其他零件；多余长度按实物改短。
4. **斗身小口插入接座。**公头外22.8×18.8、母座内23.2×19.2，名义插入5.8mm，底部留0.2mm轴向间隙，避免顶环和闸盒两端把斗身夹压变形。上斗已由顶环4颗螺栓固定，下接头不需要胶封死。入口18.4×14.4逐渐收回18×14，以减小接缝处朝上的台阶；内侧仍须手摸、照光、试豆检查。
5. **下斗小口穿过工作台60×60孔。**90×90×4法兰的底面Z186贴木台上面；法兰中心与豆路同为X110/Y120。四孔φ3.4：X73/147、Y83/157；相对工作板左前角X22/Y22，即X51/125、Y61/135。配M3×16、平垫、防松螺母4套，木台6＋法兰4=10mm，按垫片／螺母复核长度。
6. **先不接舵机，手推闸片。**新接座不得压缩原2.3mm导槽；豆子通道仍为18×14，下方短管出口Z300、观察带235–285、下斗大口Z220。先用单颗实豆确认出入顺畅、没有残留支撑／毛丝、下斗不蹭木孔，再做空载舵机检查。卡紧先拆检或修配，不能靠舵机硬顶。

## 可修改源文件和验证范围

改`parameters.json`中的壁厚、配合间隙和固定法兰尺寸后，在独立Python环境安装`requirements.txt`，运行`build_print_models.py`；不安装到训练`.venv`。导出脚本同时检查CAD单实体、STL封闭／法向、STEP回读、上斗与接座不相交、下斗与60mm木孔不相交及保留的闸片净空，见`validation.json`和`manifest.json`。脚本使用CadQuery 2.7.0。支持、孔的实际尺寸、外形翘曲和强度均未实打验证。

原H3文件哈希保存在`h3-preserved.json`，P1作为新增打印备选，不覆盖PP焊接版图纸、BOM、动画或固件。`BOM-delta.csv`列出替换和新增紧固件，不应把P1与原PP漏斗各买一套。

预览页使用本地Three.js 0.160.1；许可见`THREE-LICENSE.txt`，HTML已内嵌依赖，无需网络。`requirements-lock.txt`记录本次CAD生成环境，不修改项目训练环境。
