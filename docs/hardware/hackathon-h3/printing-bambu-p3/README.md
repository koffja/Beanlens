# H3-Bambu-P3：拓竹设备打印包

2026-10-22。用户确认：A1、X2D、**X1 Carbon**、P2S、H2D；原厂标准**0.4mm喷嘴**、**拓竹PETG HF**、**拓竹纹理PEI板**。本包将P1漏斗与P2支架整理成机型专用的已切片文件，**没有更改装配尺寸**。

先打开[打印总览](index.html)。`jobs/`内的 **`.gcode.3mf`已包含实际G-code**，不是上一版仅有几何模型的通用3MF。由本机Bambu Studio **02.08.02.61**实际切片，五种机型各6盘，共30个文件。**整套只需选择一组打印任务，不是把五个机型目录都打印一遍。**

全部为主机切片／文件检查，**尚未实打、试配或在这几台设备的固件上验收**。先打00试配片再打主件；温度、板材、喷嘴或机型不符时，应打开工程修改并重新切片，不直接使用原G-code。没有发送文件到打印机，也没有启动打印。

## 建议怎样分配机器

所有零件均小于已确认的220平台，不需要H2D的大平台，也不需要更换喷嘴。A1同样能打PETG；把较大的斗身交给静止热床的机器，是本次排产和摆放的选择，不代表A1不能打印。机型能力核对见[拓竹官方参数比较](https://bambulab.cn/zh-cn/compare)、[A1原厂规格](https://uk.store.bambulab.com/products/a1)、[X1 Carbon原厂规格](https://public-cdn.bambulab.com/store/bambulab-X1-carbon-tech-specs.pdf)。

**比赛赶时间，推荐四台并行**：

| 机器 | 打印任务 | 本次切片估时 | 说明 |
| --- | --- | --- | --- |
| P2S | 00试配片 → 01上漏斗 | 约18分＋3小时26分 | 上斗和接座分机时，试片要交叉试插 |
| X1 Carbon | 00试配片 → 02接座＋前后相机座 | 约20分＋2小时39分 | 与P2S的公／母试片交叉核对，再放行主件 |
| X2D | 03下接豆斗 | 约3小时50分 | 只用主热端，PETG自身支撑；不用双料 |
| A1 | 04舵机架 → 05两限位座＋旗片 | 约2小时10分＋55分 | 舵机架需要清理承梁下支撑 |
| H2D | 备用或代替任一台 | 见总览 | 本包使用左侧1号标准热端单材料，不启用双料支撑 |

四台可将打印阶段安排在约4小时量级，**不包含排队、烘料、冷却、拆撑、失误重打及装配时间**；不是现场完成承诺。按上表组合，总用料约255g（包含两套试片），每台同时打印都须有各自可用的干燥料盘。多打的一对试片约3–4g，属于跨机器匹配检查。

**只开两台**：P2S打印00、01、04、05；X1 Carbon打印00、02、03。两台各约6.5–7小时切片预算，照样可以完成整套。X2D和H2D不必因为更高规格而强行参与；需要替换时用对应目录中的同号文件。

## 已优化哪些打印设置

共同设置为0.20mm层高、0.20mm首层、5层顶底、Gyroid填充、Arachne墙生成；外墙60mm/s、内墙100mm/s、首层20mm/s，体积流量上限10mm³/s。按零件设置壁数、填充与支撑，不使用机器的最高速度作为本次首件目标。

材料温度和机型启动／结束流程沿用已安装版本的**各机型原厂PETG HF配置**。本次导出中P2S／X1C／X2D／H2D为首层230℃、后续245℃，A1为首层230℃、后续240℃；纹理PEI床温70℃。这些是已切片设置，不要在打印中随意改成其他材料。体积流量限制是本次原型候选，不是已经实测的耗材性能。

下斗比较了树状、默认普通、贴合普通三种方案。最终贴合普通支撑的基体间距4mm、接触层3层／间距0.4mm、顶部Z间距0.2mm，P2S估时从4小时46分降至3小时52分，材料约72.2g增至77.9g。选择较少绕行、便于从外侧拆除的方案；**可拆性尚需首件验证**。五台的实际G-code支撑线段均检查过，下斗内部通道未出现支撑挤出路径。比较记录见`support-comparison.json`。

没有统一缩放、加孔补偿或改配合间隙。P1公头／母孔每侧0.2mm候选间隙仍保留，需要00试片验证。实际相机PCB孔距、舵机耳孔仍先对P2纸样；切片无法解决实物尺寸不同的问题。

## 上机顺序

1. **先烘干PETG HF并保持干燥供料。**原厂给出的热风烘料起点为65℃、8小时；使用耗材／烘料设备说明允许的方式。湿料的毛丝、爆泡和尺寸不稳不能靠降低速度完全解决。[拓竹PETG HF说明](https://bambulab.com/es-mx/filament/petg-hf)
2. **核对喷嘴与板材。**使用原厂标准0.4mm热端和纹理PEI板；清洁板面，按原厂板材指引准备表面。本包不适用于直接套用0.6mm、光面板、冷板或其他品牌PETG。若实机装高流量热端，先在Studio选准确的热端变体并重新切片。
3. **按总览选择文件。**在Bambu Studio打开对应机型的`.gcode.3mf`，选择打开完整项目／保留工程配置，不只导入几何。进入预览核对部件、支撑、机型、0.4喷嘴、PETG HF、纹理PEI。若软件提示重新切片，使用其中的配置重新切片并检查，不忽略机型警告。可先使用本次已验证的Studio 02.08.02.61。
4. **先打00。**跨机器打上斗与接座时，两台分别打印00，各自冷却、清毛丝后，再用“上斗所在机的公头＋接座所在机的母孔”试插。应可手插拔、不明显晃动；卡紧先查象脚／毛丝，仍不合适就调整P1参数并重新出图、重新切片。不要整件缩放或靠螺钉压入。
5. **通过试配后再开主件。**在发送页映射实际装入的PETG HF料盘／外置料，预览颜色只作显示；单材料不要求AMS。保留正常的调平／校准，按机型PETG通风指引打印，不额外开启高温腔体加热。首层确认贴床、无卷边后再继续。
6. **也可用存储卡／U盘。**将已切片文件完整复制到对应机器支持的介质，用机型文件名核对后选择打印；不要把P2S目录文件放到X1C或H2D上代用。物理介质接口按实机为准。打印期间不需要本项目代码运行。
7. **冷却后拆撑。**下斗从四周拆法兰下支撑，不从豆路硬撬；舵机架清掉耳梁下支撑，确认能放入螺母。去除裙边、毛丝、碎屑后照光、手摸检查豆路。孔位先手穿螺钉，不强拧扩孔；先空载、再单豆。

## 与P1／P2装配的关系

本包只改切片与摆盘，**P2配套装配修订仍然需要实施**：60×60×3铝板移至X153/Y159；后承托片改PP3 68×80并开20×30避让窗；新增180mm后横梁，可裁库存400余料；后闸盒贯穿螺栓改M3×25候选；新旗片替换旧件。舵机轴心、光轴和原闸片滑缝不变。

完整安装和孔位说明已随包附于`original-cad-kits/`中的原P1与P2 ZIP，解压阅读各自README。P2还包含舵机／相机1:1纸样。不要因换打印机而改变装配坐标，或把安装参考STEP整机直接打印。

## 文件与检查范围

- `jobs/机型/`：对应机器的6个已切片文件；`X1C`就是用户确认的X1 Carbon。
- `index.html`：离线总览，可按机型查看每盘下载、时长和重量；`print-jobs.csv`便于排产。
- `configs/`：从安装的官方预设展开的完整配置，含本次过程调整；`models/`只按毫米平移摆盘，保留原打印方向与尺寸。
- `prepare_jobs.py`：生成／切片来源；`validate_jobs.py`、`validation.json`：实际切片与文件检查；`logs/`：每盘结果记录。运行使用独立CAD环境，不是训练`.venv`。
- 原P1／P2共148个文件哈希逐项保留，见`previous-preserved.json`；未改固件、用户bringup或训练资料。

主机检查包含：原网格尺寸／体积、30盘切片成功状态、3MF结构与G-code校验、机型ID／喷嘴／材料／板材、物体数量、下斗支撑通道避让。**未验证实际打印成功率、孔精度、支撑拆除、承载、寿命或设备固件兼容性**。所有估时和克重均是切片估算，实机可能不同。

技术记录：此Mac版CLI查询`machine_full/`但安装包使用`machine/`，因此导出缺失的`printer_model_id`按同版本原厂机型文件补齐，未修改G-code。日志中的`Invalid T command (T65535)`来自保留的原厂结束代码，最终切片状态为Success；没有删改原厂启动／结束动作。来源见[官方CLI文档](https://github.com/bambulab/BambuStudio/wiki/Command-Line-Usage)、[官方CLI实现](https://github.com/bambulab/BambuStudio/blob/master/src/BambuStudio.cpp)。
