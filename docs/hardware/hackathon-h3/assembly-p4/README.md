## 怎样看图

1. 先看“整机组装”：青色为9件打印件，木色为海洋板，黑色槽形件为2020，银色为铝板／角码，浅色为PP，金色为紧固件。
2. 点“整机爆炸”认件。右侧选J01–J14的一处连接，就会只保留相关零件，显示螺丝规格和穿过顺序。
3. 拖“拆开程度”查看贴合面；点击部件查编号与BOM。材质复选框可暂时隐藏木板、型材或遮光片；隐藏是看内部，不表示取消安装。
4. 纸样在`templates/`。按实际尺寸100%打印，量50mm标尺并贴合实物，再钻孔。侧片纸样建议A4横向；A3图册本身不是1:1模板。

**M5×8／×10均是当前2／3／4mm连接层的候选**，不能保证所有商家的T螺母通用。先用一只实际槽母试装，确认有足够螺纹啮合、螺钉不顶槽底、角码确实夹紧，再批量装。标准成品角码若比2mm厚，按实际厚度重新选长，不硬用图中的螺长。原厂型材／连接件的尺寸与适用螺钉也须成套匹配，可参考[米思米框架连接资料](https://uk.misumi-ec.com/files/images/products/docs/framingsupport.pdf)，不能把不同系列槽型当同一零件。

## PP、铝片与海洋板怎样加工

- PP3一片300×300可排顶环176×196、两盖50×85、后承托68×80；保留3mm切缝。PP2余料只做内18×14下短管与前U封口。先拆铝片和PET垫条，再外焊固定件，冷却修平后装导槽；不能焊死可拆盖板。
- 前U封口前片54×8.3×2，侧翼各16×8.3×2；侧翼放盖板两外侧X83/135，不放在盖板内部。前壁封闭不表示内侧一张薄板能无缝穿过闸缝；内焊筋、毛边与台阶仍要实豆核对。
- 角铝买20×20×2、1m候选原料。切4只宽40、16只宽20，共480净长＋约60锯缝，余约460。每类孔轴不同：穿木板的孔与锁柱的孔分别钻在两翼，不把水平孔图转错面。
- 平片可从20×2铝扁条500mm裁8只40长，另4只12长作BOX压片；总净长368，计12道3mm锯缝404，余96。成品40×20平连接片若孔距20、两φ5.5可替代8片，不与原料方案重复购买。
- 海洋板176×196×6原料共3片：2片作底／工作台；第3片裁88、30、30，三道3mm锯缝计157，余39。板边打磨，先按纸样核孔，不用螺钉把翘曲板强拉平。
- 黑PP2一片300×300可排两片196×100与两片110×47（背景片旋转摆右侧）。侧片两端木条槽10.5×6.4；右片后上去64×34；后背景右上去30×16。按模板先试套，再定灯槽卡扣孔。

## 型材与紧固件怎样下单

**不需新增型材。**4根460整根作柱；另外3根460各切200＋180；第一根400也切200＋180；第二根400切180作P28。按每刀3mm计算，余74×3、14×1、217×1，共453。旧H3是12段，本版是13段，新增后梁已含在180×5中。

BOM的“采购基准”是总需求／备件上限，不是要求重新买一套。套件已带的M5、T螺母、卡扣与隔柱先扣库存；`included_in`表示计入母项／原料，子件不重复下单。价格未知留空。

本版装机M3螺钉79颗、M5共60颗；M3大平垫158、防松螺母79；M5平垫与T螺母各60。相机另有M2×5／×8各8与8只隔柱，SS-01GL为M2×14四套。备件建议见紧固件CSV。球头杆套件、自带舵臂紧固螺钉与隔柱螺柱另按原H11/H12/H37，不能重复计算为两根连杆或两只舵臂。

## 验收顺序与边界

先按P3打印00试配片；相机PCB、MG996R耳孔先对P2纸样。空框找方 → 板材／承重片 → 打印斗／导向 → 舵机／连杆／限位 → 相机／照明／BOX → 机外电气。舵机6V断开时手推全行程约19.75，检查铝片、螺母、旗片与线束；只关开关／只开开关／中间都不触发需万用表实测。卡住先拆检，不持续加力；软件停止不称硬急停。

本轮检查覆盖固定实体互不重叠、9打印实体与原CAD一致、21个行程采样、移动紧固件窗口、两条中心光轴、BOM数量与浏览器交互。**未证明全视场、实物孔精度、真实限位触发、灯槽卡扣兼容、舵机承载、热变形或连续寿命。**所有购件外形、开关拨片、螺纹与线束仍是参考，接线沿用H3；GPIO、短曝光、双CSI和模型部署仍待实机验收。

STEP含打印件与固定结构，器件用包络参考；详细舵臂、连杆、灯槽外形在HTML中重建。不要把整机STEP或爆炸状态拿去打印。`assembly-data.json`为本版坐标源，`build_assembly.py`为集成CAD源，`build_bom.py`与`build_templates.py`同步资料；独立基线为`config/hardware-hackathon-h3-p4.json`。旧文件哈希见`previous-preserved.json`，未改训练`.venv`、固件、用户Excel或既有P3切片。
