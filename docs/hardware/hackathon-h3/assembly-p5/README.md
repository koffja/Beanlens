## 怎样看交互图

先“整机组装”，再“整机爆炸”认件；右侧选J01–J14中列出的10处连接（编号保留P4含义，J07/08/09/11已取消）。拖“拆开程度”看贴面，点零件查BOM。青色打印、木色海洋板、黑色2020、银色角铝、浅色PP、金色螺丝。紫虚线表示CSI走向参考；相机特写可见两条水平光轴。

点“演示人工投豆”看准备→人工投一颗→下落抓拍→同杯收豆→核图的顺序。缺图／糊图分支会提示暂停，**豆已落杯，不能留在闸上，也不能自动分选或追回**。按钮／时间轴和7秒教学时长不代表已实现固件或实测时序。

## 左右相机如何固定、排线怎样试套

坐标：X左右、Y前后（前为小Y）、Z向上，单位mm。

1. 左木条W05：X−18…12、Y20…220；右W04：X208…238、Y20…220；底234、顶240。两条均200×30×6。
2. 每条两端各一只20×20×2角铝，裁宽40并沿X放。左托片覆盖X−20…20，右200…240；前端Y20…40，后端200…220。竖翼M5锁前／后柱的Y向槽，横翼M3×16穿木条。左右孔为镜像，不能只用旧20宽托片。
3. 木条4孔沿长边在10、74、126、190处，短边中线15；中间两孔固定打印座，两端孔接托片。前后两颗相机脚螺丝给座调角，不夹镜筒。
4. P22原前座转90°装右；P23原后座转90°装左。保持Z260光轴，镜头面对中心110/120；相机PCB与打印背板间沿用8mm内内M2隔柱。两端分别M2×5和×8候选，不用一根长螺丝通穿隔柱。
5. BOX承板整体降低110mm，底224、顶312，前Y20；原壳屏中心约Z260。4压片、20mm通孔隔柱与接口避让沿用P4，先松装核CSI、KEY、USB及TF可达，不在PCB上钻孔。
6. 先断电，把实际两条CSI排线从BOX接口绕到左右相机，留自然弯曲与少量松量，并在框架固定线端。图示两段折线路径约145／138mm，只是参考；**未包含真实接口出线、插入深度、弯曲半径及服务余量，不能因此保证200mm线一定够用**。20cm是机械布置目标，不是已核线材可用长度。线不够先停下，不拉紧排线或通电插拔。

## 顶部PP与上下斗

顶部PP板200×180×3，装配X宽180、Y深200，左前20/20，底440。它与框内口名义刚好，先去毛刺试套；尺寸误差或框不方时局部少量修边，不靠螺钉挤入。顶板中心80×80孔，板内左前50/60；4上斗孔为板内X44/136、Y54/146（全局64/156、74/166）。4平片孔全局X30/190、Y60/180。

四只40×20×2平片仍在顶部深梁底面：外孔M5×8向上入底槽，内孔M3×12穿PP和片，两侧用φ9大垫片；上斗4孔M3×16，法兰贴PP下面。上斗靠法兰承重，P12接座整件不装，打印颈出口Z329.5直接进入开放拍摄段。内18×14出口不保证自动单粒，**比赛不储一斗豆，每次手放一颗**；卡豆时停投、断电取出，不用工具往通电设备里捅。

下斗P13原件仍落在工作台顶Z186，四孔X73/147、Y83/157；上口220、下口160，下方同一杯。实际偏落、反弹、镜头视野和整颗豆是否入画仍需实豆验证。

## 灯带怎样直接装在20角铝

每只竖角铝20×20×2、长120，底186、顶306；100mm灯带贴Z206…306。位置4处：X50或150，前Y50…70、后Y170…190。灯带贴平面而非角内棱，前两条朝后、后两条朝前。角铝是固定载体与散热面，不是自动获得足够散热的保证。

1. 裁4只120竖角铝、4只宽20脚角片，锯口去毛刺。竖角铝底端8、16处各开一φ3.4连接孔；脚角片竖翼对应同样两孔。
2. 前脚横翼位Y30…50、后Y190…210；木台新增8孔：X55/65/155/165，Y40/200。每脚2颗M3×16穿角片2＋木板6，竖翼另2颗M3×10配外φ7平垫锁竖角铝，防止围绕单颗螺丝转动。
3. 清洁干燥角铝，贴适宽耐温导热背胶，再贴灯带背面。实际灯宽候选≤12mm；裁剪必须按所购灯带标示剪切点，100mm仅目标有效长度。焊点和端头热缩绝缘，不让铜焊盘碰铝；灯带线路不钻孔。
4. 电线沿角铝外侧与木板固定，留线端松量；不跨落豆／拍摄中心。首件先点灯10分钟检查背胶、温升、阴影、眩光和两路短曝光。实测热时先停机改善固定／散热，不让背胶或PETG受热变形。

本版取消四面PP拍摄腔，便于比赛快速搭建；现场环境光可能影响曝光，需实测。需要临时遮光时在光路外用独立黑背景，别直接恢复P4挡住左右镜头的带孔板。

- **黑2020无需新增。**最终460×4＋200×4＋180×4共12段。3根460各切200＋180，1根400同切；每刀3mm时余74×3＋14＋整根400＝636mm。若P4后梁已切，保留不用；型材库存不因此减少可用框架件。
- 海洋板按W01–W05五件核库存。旧底板、开孔工作台、BOX板可复用；相机条另订200×30×6两条。原第三片176×196可裁BOX板，但裁不出200长相机条。
- 20角铝净用：8×40＋8×20＋4×120＝960mm，20刀×3mm后1020mm，**一根1m不够**。全新原料按2根1m；已有P4角片与余料先扣除。第1根4×120＋8×40＋12刀＝836，余164；第2根8×20＋8刀＝184，余816。
- 20×2扁条500mm可裁8×40＋4×12，总净368＋36锯缝＝404，仍足够。灯带无需另购铝槽、卡扣或2mmPP灯板。
- 装机M3螺钉52、M5×8螺钉52；M3防松螺母52、φ9平垫88、φ7平垫16，M5槽母／平垫各52。相机另M2×5与×8各8、8mm内内隔柱8。采购表含备件基准，扣原套件，不重新买全套。

原9打印主件仅安装4件：P11、P13、P22、P23。P3现有01／03盘可照匹配机型与材料使用；02盘含不装的P12，若已有全盘切片可保留多打件，尚未打印则在Studio仅留两相机座后重新切片。不能删改已切G-code来跳过P12；04／05舵机与限位盘本版不用。没有为P5重切片或发送打印。

## 新接线与比赛流程

机外YU2405 24V5A→总开关／保险／分线：一支24V灯带，一支TPS5450候选成品板降5V，通过适配BOX的成品USB线供电。摄像头只接配套CSI接口并由接口供电。**无6V、无UBEC、无PWM缓冲、无外接限位；J10本版不接。**不在已通电USB之外再给主板电源针并联供电。预算5V×3A÷0.8＋灯8W＝26.75W，只是选型预算，不是实测耗电。

先断电核接线与输出极性，空载量5.00V，再接BOX；确认两相机映射与连续采集、焦点、短曝光及缓存，屏幕提示准备好后人工投一颗。两视角缺图、糊图、多豆或配对不明要记录待复核，并提示人暂停下一颗；未判定不能算正常。同一杯没有坏豆分选，必要时整杯标记待复核。KEY1只停止采集许可并提示人，不能机械拦住已投入的豆。双摄不等于硬件同步或全表面覆盖。
