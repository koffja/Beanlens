## 相机怎样直接粘

坐标X为左右、Y为前后（小Y在前）、Z向上，单位mm。长200沿Y、宽40沿X，不是把200长木条横向伸进豆路。板厚沿用6。

| 对象 | 参考安装位置 |
| --- | --- |
| 左木条W05 | X0…40，Y20…220，Z234…240 |
| 右木条W04 | X180…220，Y20…220，Z234…240 |
| 左／右PCB内表面 | 约X40／180；PCB底边Z240，参考40mm高 |
| 左／右镜头前端 | 约X54.8／165.2，Y120，Z260 |
| 镜头间距 | 约110.4mm；用户接受约110；精确值由实际镜筒伸出量决定 |
| 胶脚示意 | 每相机2处，背面下沿Y110…118／122…130，避开四角孔；名义三角截面8×8 |

1. 木面打磨、封边并保持干燥。两条新木板需要200×40，旧30宽木条无法直接加宽。两端托片的木板孔居中：距长边端10／190、距短边20，φ3.4。两只角铝各锁一端，相机本身不再打螺钉孔。
2. PCB必须**竖直**，镜头指向中央豆路。底边放在木板顶面，PCB镜头侧朝内；不是将PCB平躺，也不是用胶承住镜筒。
3. 先用临时胶带／夹具定位，断电插排线后通两路图像，核对焦点、画面角度、遮光孔与ROI。参考距离每镜头到豆路仅约55mm；这不是已经验证的镜头近焦能力。画面不清楚时先别粘牢，按实际模组允许的调焦方式处理。
4. 在PCB**背面下沿的空白边**与木面之间点两个可剥离绝缘胶脚。名义胶脚只表示位置和支承方向，不是已验证的胶量／强度。先在废料上试胶温度、粘性与拆卸，再试相机；不盖焊盘、四角孔、连接器、芯片散热面或镜筒。实际板没有空白边时先重新找固定点，不能照示意强行点胶。
5. 排线单独在木板／框上做卸力，给接头留自然松弯。试推相机若松动／歪斜，停止投豆，重新定位粘接。近焦和双图清楚后，再装罩复查。

胶为电子装配用非导电、可剥离固定胶候选；BOM列低温热熔胶方向，具体胶与胶枪温度／PCB适用性待核。不采用导电胶或酸性胶；也不把普通强力双面胶的薄PCB底边接触当作已通过的支架。P22/P23及其M2螺钉、8mm隔柱本版全部取消，旧原件仍保留。

## 相机木条与托片怎样齐框

相机支承角铝仍20×20×2、宽40，共4只，但从原来外伸的位置移到左X0…40、右180…220。水平翼居中φ3.4孔锁木条，柱侧翼偏φ5.5孔锁前／后柱槽；左右镜像。每侧2套M3×16和2套M5×8，不能把旧偏孔照搬成新孔。

实购角铝弯角与型材槽母先试配；旧角片能否改孔取决于新旧孔的边距，孔挤在一起就换该段。模型的木条与铝片外轮廓不超出220宽，螺钉头／垫片示意不代表所有商家硬件都完全平齐。

## BOX上移到哪里

背板仍176×88×6、前Y20；整组底Z352、顶Z440，顶边贴近上层横梁的下缘。BOX原壳、压片、隔柱20及背板一起移动128，原壳不钻PCB。屏幕位置提高，上斗与进豆口保持P6。

**不能把四只角铝全部原样上移。**几何检查发现，上面两只A11/A12会撞上顶框已有角码。P7只把这对角铝再下让30；下面两只不变。

| 背板孔 | 全局坐标／从板顶量 |
| --- | --- |
| 两排柱角铝 | X30/190，Z368/394；从板顶72/46，φ3.4 |
| BOX隔柱四孔 | X74/146，Z364/416；从板顶76/24，φ3.4 |
| 背板原点 | 左下X22/Z352；孔图纸上方是板顶440 |

旧背板可补钻新的上排托片孔；原上孔封边后闲置。上排与下排托片间距仅26，是避角码后的实际图示；先轻紧找正，再核屏幕与USB／KEY／TF／J7可达，不要压排线。

CSI虚线路径每路约165.3mm，是候选折线长度，**未测真实接头位置／插入段／弯曲半径**。20cm排线尚不能写成“确定够用”。先断电按实物自然走线，确认有余量，再粘相机；不够时调整路线或核兼容排线，不能拉紧／硬折。5V降压模块尽量靠近BOX，让J7的22AWG支线仍短于200mm；较长距离走24V干线，不靠加长细5V线补位置。

## 遮光罩只取消顶盖

保留SH-L/R两侧、SH-F/B前后和SH-D底片，共5片黑PP2；两侧φ32镜头孔仍在Y120/Z260。相机更靠内，镜筒穿孔后前端进入罩内，PCB留在罩外。侧片本身不承重相机，镜筒也不能被孔边夹住。

- 取消SH-T和4只SA-T顶承角片、8套M3×10；新侧片不再开旧Z322顶盖孔，旧片可保留闲置孔。
- 仍有4只竖角片连接前后罩、4只下承角片连接底片，共8只20宽角片。
- 侧片到灯架8套、竖角片8套、底承角片8套，共24套M3×10。顶盖取消不会让前后／底片悬空。
- 交互图黑色／透明／隐藏切换真实5片；“看遮光罩怎样固定”进入J15。透明仅教学查看，实物PP不透明。

顶部敞开，环境光会变化；近焦、曝光、反光、ROI和缺图率重新实测。φ32只按当前目标区域光线检查，不宣称全部90°视场都无遮挡，也不宣称完全光密。

## 沿用的木板、漏斗与供电

三块大板仍240×220×6，220沿X、240沿Y：W06整顶板底460，不切角；W01底板底22、4片PP2垫片；W02下斗承板底180；后两块四角22.5方口，中央孔和P11/P13法兰位置保持P6。上斗颈出口349.5、下斗上口220／出口160，人工单颗掉入同一杯。只装P11/P13两个原打印体，无须重打。

5V仍J7-1=GND、J7-2=VCC_5V，3–6留空绝缘，拟2A直流保险；J7与Type-C1供电二选一。J7绕过USB输入限流，实物针向／电压／接头额定／温升须核。详见[接线说明](power-j7-p7.html)及保留的原厂原理图引用。不装执行器，J10无本版外设。

P3仅需匹配机器的00试片、01上斗、03下斗盘；02相机座/接座、04/05执行器盘不用。旧模型与已切G-code不改，不自行发送或开机打印。
