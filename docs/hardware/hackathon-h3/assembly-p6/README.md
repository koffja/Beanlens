## 遮光片原先为什么切换无效

P5取消了遮光罩模型，但页面保留了材质开关；浏览器复现为0片遮光件，切换前后可见部件相同。这是旧页面遗漏。

P6真正增加六片黑PP：SH-L/R两侧有φ32镜头孔，SH-F/B在前后，SH-T在上方带进豆孔，SH-D在下方带下斗孔。它们包在四条灯带外面，相机在罩外；前片位于BOX承板后方，不挡屏幕。实物黑色不透明。

- **黑色实物**：默认显示六片，能直接看到黑罩位置。
- **透明看内部**：六片仍在，只降低透明度以查看相机、灯带、豆路。
- **隐藏**：六片从视图中隐藏；物料图例的“遮光罩6片”勾选与此同步。
- 点“看遮光罩怎样固定”进入J15；爆炸外移只是认件，不是装配间距。开始人工落豆演示时自动改为透明，便于看豆，实物不会透明。

## 三块240×220海洋板怎样安装

尺寸单位mm，沿用6mm厚海洋板；**220沿左右X，240沿前后Y**，与220×240裸框外轮廓对应。前方为小Y，Z向上。

| 编号 | 外形与缺口 | 放置／固定 |
| --- | --- | --- |
| W06顶板 | 240×220×6整板，不切角；中80方孔 | 直接盖在顶框上方，底460顶466；4颗M5×12候选直锁顶槽 |
| W01底板 | 同毛坯，四角各切22.5×22.5 | 4只黑PP2垫片放底梁顶，板底22顶28；4颗M5×14候选穿板、垫片锁槽 |
| W02下斗承板 | 同毛坯，四角各切22.5；中60方孔 | 板底180顶186；原4只40宽角铝支承并锁立柱 |

**为什么不是只切20或20.5？**立柱是20方，底框角码的竖翼还向内占约2mm。CAD试算20.5仍碰角码，改22.5才能留名义0.5余量。两块嵌角板统一缺口，视觉和加工一致；如果实购角码更厚，先对实物试套，不靠螺钉硬拉。

底板四角“嵌入”是缺口抱住立柱，板边与框外轮廓齐平；它仍由底梁／垫片支承，**不能让整块木板与同高度的实心横梁重叠**。4只40×20×2黑PP垫片避开底框水平角码；普通杯底仍Z28。木板切口打磨、封边并保持干燥。

## 遮光罩具体连接路径

**工作台 → 四灯架脚 → 四竖角铝 → 两侧PP → 前后／顶底PP。**灯带直接贴角铝的平面翼；PP锁另一回折翼，不穿灯带线路。右侧两竖角铝回折翼朝外，先按P6方向标孔；旧孔若边距不足就换该段，不能硬挪孔。

| 零件 | 成品尺寸 | 安装位置／用途 |
| --- | --- | --- |
| SH-L/R | 黑PP2，152×110，两片，φ32镜头孔 | 左X48…50，右170…172；Y44…196，Z222…332；孔中心Y120/Z260 |
| SH-F/B | 黑PP2，120×110，两片 | 前Y44…46，后194…196；上部两孔接竖角片 |
| SH-T | 黑PP2，120×148 | 底Z332，中30×26进豆孔；上斗颈在其上15.5 |
| SH-D | 黑PP2，116×148 | 底Z222，中72方孔给下斗；四角20×26让灯架 |
| S10 | 20×20×2角铝，宽20，共12 | 四竖角、四顶承、四底承 |

1. 每侧片4颗M3×10锁灯架回折翼：Y60/180、Z250/294；LED粘在另一翼。灯条仍Z206…306，脚连接处用外φ7平垫。
2. 4只竖角片位于Z308…328，高于灯架顶306，避免实体相穿；各2颗M3×10连接侧片与前／后片。
3. 顶／底各4只承托角片位于Y90/150，每片2颗M3×10，一颗穿侧PP、一颗穿顶／底PP。总32套M3×10，罩片不能只画成悬空面。
4. 先松装侧片对光轴，再装前后和顶底；最后用实豆核暗角与偏落。φ32只按目标ROI候选，不能保证整个90°画幅都无遮挡。

罩保留进／出豆和装配通风间隙，用于挡侧面环境光，**不宣称完全光密**。实际漏光、灯带温升与焦点须测；不要为了遮光把散热面、排线和通风全部封死。

## 供电改用J7

[逐针大图](power-j7-p6.svg)已经标明：**J7-1=GND，J7-2=VCC_5V**。两脚直接连板上电源母线；J7是2×3、2.54mm排针，不是PH2.0或GPIO口J10。脚号以原厂图为准，实物插接方向仍须认丝印／方焊盘，并断电测GND导通。

- YU2405 24V进机外低压盒，仍分24V灯带与TPS5450候选整板。
- 降压空载调5.00V，正线经新增2A直流保险到J7-2，负线到J7-1。5V短线选22AWG约0.34mm²、目标≤200mm，母端子额定电流、压接和温升先核，不用松散单芯跳线。
- J7-3/4为SPK−/SPK+，5/6为ADC_1/ADC_0，本机不接并绝缘；不能误接5V。
- **J7外供与Type-C1供电二选一。**接CanMV IDE的USB1前先拔J7供电；Type-C2仅USB串口且不供电，不能代替USB1的IDE／USB设备通道。

按原理图，USB1 VBUS经过U5 MT9700再到VCC_5V，J7外供绕过这条限流路径。2A外部保险为试制起点，不能替代稳压和极性检查。模块可留≥3A能力余量，但不是给排针或板内走线认证3A；启动、双摄、电压降与温升未实测。若保险误断，先排查实际电流和接触问题，不直接加大。

原厂[接口说明](https://wiki.alientek.com/docs/Boards/Kendryte/DNK230D/start-guide/k230d-box-introduction/)列出5V/GND排针及USB两口差异；具体J7脚号与供电网络来自[原厂原理图副本](references/ATK-DNK230D-V1.0.pdf)第3／1页，SHA-256见[来源记录](references/source-check.json)。未修改原件。

## BOM、裁切与打印

59行BOM区分原料、加工子件、备件，不重复采购。6件海洋板中三块240×220需按新图加工；黑PP2用400×300一片，可排6罩片及4支承垫片。20角铝净1200＋32刀×3＝1296，两根1m仍够、共余704；如果P5已经裁好，新增12只20宽角片从余料取。20×2扁条只留4只12长BOX压片，旧顶底8平片不再安装。

黑2020仍12段：460×4＋200×4＋180×4；现有7×460＋2×400够用，3mm锯缝余636，不新增型材。装机M3螺钉76、M5螺钉52；M3φ9平垫136、φ7平垫16，M3螺母76，M5槽母／平垫各52；M2相机螺钉与8mm隔柱另列。

4件原打印几何及P3切片不改，只有上斗装配高度变化。P3第02盘含本版不用的P12，未打时可在Studio删该模型后重新切片，不能编辑已切G-code；04／05舵机限位盘不用。本轮没有切片、发送或开机打印。

## 纸样和验收

三块大板的完整SVG请用A3竖向100%打印；没有A3可用6页A4分幅PDF，每板两页重叠20mm，沿X110虚线对齐。必须关闭“适合页面”、量50mm标尺；图册不是1:1模板。

先空框找方 → 缺口试套／垫片／托片 → 三大板和上下斗 → 相机／BOX／灯架 → 六片罩 → 断电接线核5V → 双摄焦点／短曝光 → 单豆。漏图、糊图、多豆、配对不明记录待复核并提示停投；豆已落同杯，系统没有机械阻拦／追回功能。

`geometry-check.json`为固定实体、四打印体积、中心／目标ROI角光线、落豆中心及LED紧固件的主机检查。`browser-check.json`验证6片实际显示及黑／透明／隐藏图像差异。它们不证明实物孔精度、承载、全视场、散热、排针额定、双摄抓拍或整机功能已验收。原852份硬件文件校验保留，未改训练、用户固件或数据。ZIP含离线页面、PDF、纸样与基线；源重建需要完整项目P1/P2/P4和独立CAD环境。
