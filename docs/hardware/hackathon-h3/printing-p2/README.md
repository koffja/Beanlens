## 采用P2必须一起修改的固定结构

本轮实体检查发现，旧H3示意的60方铝板右后角侵入右后立柱包络；原大PP承托片也穿过舵机机身。旧图只是外形示意，不能直接照其重叠位置加工。**P2是一次必要的装配修订**，不是原支架材质直接替换。H3与P1旧文件原字节保留。

1. **60×60×3铝板保留，改安装位置。**左前下角变为X153/Y159/Z280.2，右后角到X213/Y219，避开Y220开始的后立柱。舵机轴心仍为X170/Y180/Z331。打印架底面贴铝板上表面Z283.2。
2. **金属角码装右后立柱前面。**候选40×40×4、宽20的加强角码，竖边用两颗M5/T螺母锁前槽；水平边向前托铝板右侧。图中包络X200–220/Y180–220，支承上表面Z280.2。实际角码孔型不匹配时先改孔，不靠螺钉拉弯。
3. **原176×50承托片改为PP3 68×80。**左前下角X85/Y160/Z318；不再铺进舵机区域。前端仍托原闸盒后段，后端锁新增后横梁。另开20×30贯通避让窗，窗口左前角为整机X105/Y179（板内X20/Y19），让球头和旗片的移动M3紧固件从上方经过，不擦承托片。先实物核螺母／螺钉端长度，再清边修配。
4. **新增180mm黑2020后横梁。**横梁X20–200/Y220–240/Z298–318，夹在两根后立柱之间。用2只金属2020角码固定端部，承托片底面贴其顶面Z318。可从原库存剩余400mm整根裁180，留锯缝；无需专门再订型材。原角码备用件够用时优先复用。
5. **闸盒后侧两根连接螺栓改M3×25候选。**P1夹层11.3加承托片3=14.3mm，再核垫片／螺母；前侧两根仍按P1的M3×20候选。滑动间隙2.3mm和原铝闸片位置均不变。

纸样：[铝板1:1孔图](templates/aluminum-base.svg)、[新承托片1:1图](templates/carrier.svg)。实际尺寸打印，先量图中50mm标尺；纸样贴合实物复核后再钻，不能“适应页面”。PP3承托片可从余料裁；本包没有将它打印成大薄片。

## 舵机架P21

底面包络56×68，名义高35.8；4mm主壁、5mm底脚、6mm安装耳承梁、外侧三角筋。底部有机身窗口和后出线缺口。两侧留名义0.6mm壳体净空，不要求夹紧机壳。支承安装耳下表面为Z319，输出轴目标331；**耳面到轴心12mm是当前布局候选，必须量手里舵机再确认**。

先打印[舵机耳孔纸样](templates/servo-ear-check.svg)对孔。候选耳孔X164.45/175.25、Y168.5/216.2，横向6.4×3.4长槽只有小范围调整，不能覆盖所有MG996R兼容外壳。底脚4孔接铝板：X159/193、Y165/213。先松装、手装舵机，确认轴心和安装耳高度后再轻紧。

建议准备：底脚M3×12＋两侧垫片／防松螺母4套；安装耳M3×16候选4套；铝板到金属角码M3×12候选2套。耳孔若实际需要M4或尺寸落在槽外，先改源文件；不要给舵机原壳强行扩孔。耳梁下方留有螺母操作空间。不要把3.4孔当作能直接攻塑料螺纹的孔。

## 双摄座P22/P23

两件互为前后安装方向，底面60×28、总高48，底面贴前／后木横条上表面Z240。前座Y2–30，后座Y210–238；木条仍是176×30×6。

孔槽候选覆盖**24–34mm的方形四孔孔距**，默认32；不是任意GC2093模组通用。先用[相机1:1对孔图](templates/camera-hole-check.svg)贴PCB核对孔、元件和排线空间。不能给PCB照图钻孔。若孔距非方形或PCB太大，改参数／建模函数后重出文件；不要缩放整个支架。

PCB靠M2隔柱固定，候选8mm隔柱＋实配垫片，每摄4套。M2螺钉长度由实际PCB厚、隔柱及螺母决定，模型按40方PCB参考包络校核，未收到实物验证。PCB元件不直接压打印座，镜头筒不作为夹持面。名义镜头保持A(110,30,260)、B(110,210,260)水平相向，实际纵深按模组镜头突出量／隔柱和底脚长槽调整后再调焦。

底脚两M3长槽：前座螺栓候选X84/136、Y17；后座X84/136、Y223。配M3×16、平垫、防松螺母，每摄2套，穿4mm底脚＋6mm木条。相机安装会影响近焦和像素密度，不能只看光轴对准就认为图像可用。

## 两限位座与新旗片P24/P25/P26

P24固定在承托片上，底脚螺栓(144,185)/(144,193)；P25为(144,202)/(144,210)。底脚4mm厚，配M3×12候选各2套，穿PP3。侧壁在X155–159，悬臂从前后让开旗片运动路径；不能改装到舵臂上只检测转角。

两只SS-01GL都侧放：安装螺钉竖直穿过开关，杠杆沿Y方向按下。关位座上的杠杆朝后，开位座上的杠杆朝前，分别面对旗片前缘和后缘。安装孔来自欧姆龙SS资料第5页：9.5±0.1孔距，采用M2、2.4宽调节槽，**不把φ2.35孔硬塞M2.5**。每只配M2×14/16候选两套、垫片及螺母，先核有效啮合。[原厂SS尺寸及动作特性](https://omronfs.omron.com/en_US/ecb/products/pdf/en-ss.pdf)

槽长8.4mm提供沿Y调节。默认按OP名义值与约0.4mm余程候选摆位，真实FP/OP、安装方向和公差须用万用表调。**两个开关不承担舵机硬限位力；到位后也不让舵机持续顶住开关。**不是GL型号、带滚轮或更长杠杆时不能直接照本孔位／触发位置安装。

P26小旗片装在闸片尾部，低脚贴铝闸片上表面Z326；新增M3孔中心X120/Y184，与原球头孔X110/Y184分开。配M3×10候选、垫片和防松螺母。需先实物复核螺母与后支承、球头和导向盒全行程，若实际连接件包络不同先修配。旗片竖边X137–153、Y181–187、上沿Z344，避开连杆的平面路径；取代旧示意旗片，**不能两片同时装**。

先断舵机6V，手推约19.75mm全行程：闭位仅关开关导通，开位仅开开关导通，中间两者均不导通。两者同时导通、卡住、开关未复位或线被夹时先排障，不进入带豆演示。实际PWM端点、动作超时和缓关参数仍需上板标定。

## 打印起点

PETG候选，0.4喷嘴、0.2层高、5–6道墙、至少4层顶底、30–40%填充可作首件起点；温度／风扇用耗材和打印机已验证预设。壁数、方向与层间结合很重要，不能以100%填充代替结构验证。参考[Prusa PETG说明](https://help.prusa3d.com/article/petg_2059)。

- 舵机架底面贴床；前后耳梁下按切片预览添加可拆支撑，清理支撑后再装螺母。不要让支撑残屑夹在机身窗口。
- 相机座底面贴床；先按无支撑预览孔槽和侧筋。薄孔壁不要过度紧螺钉。
- 两限位座已按外侧平面侧放；按预览处理局部悬空，孔槽内不要留下支撑。需要时加约5mm裙边，取下后修边。
- 小旗片低脚贴床，竖边向上；不要把整体缩放来修孔。

模型检查覆盖单实体、闭合STL、STEP回读、打印落床、器件参考包络避让、21个连杆／旗片运动采样和两个中央光轴。**没有证明全视场、所有螺母／导线、真实开关触发、堵转承载、热变形或连续动作寿命。**先对孔、空载，再单豆，不持续堵转。
