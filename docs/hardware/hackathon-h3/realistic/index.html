一只舵臂，怎样拉直线？

固定MG996R带一只R16直臂；两颗球头和一根50mm球心距短杆，拉动铝闸片后退约20mm。两块PP盖板与侧垫条导向，前方外壳封闭。

外形重建 ≠ 原厂CAD。连杆、支架、短曝光和漏拍均待实测；落豆段慢放12×，分类画面为预设。
