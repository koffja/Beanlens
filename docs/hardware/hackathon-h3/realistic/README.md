# H3拟真教学动画

打开上层`beanlens-realistic-h3.html`，无需网络。使用本地Three.js 0.160.1及附带许可；相机/舵机/BOX沿用H1的识别性外形重建，H3重新建立顶斗、盖板导向、单槽铝闸片、R16舵臂、两球头50mm连杆、水平前后双摄和下斗。

模型尺寸来自`../design-h3.json`。平板和孔为真实网格，两个水平中央光线进行遮挡检查；这不等于全视场光学验收、装配公差或完整干涉检查。底部杯、模组孔距和标准舵机支架均须实物核对。落豆段慢放12×；A/B图和分类是预设。

`check_view.cjs`检查离线加载、状态顺序、刚性连杆、开闭端点、自由落豆、三种模式及移动端布局，并导出73帧。`export_gif.py`合成为GIF；`frames/`仅本地中间文件，不进入版本管理。构建和截图不证明板端固件或设备已运行。
