## 看懂和使用动画

先点“整机装配”看黑2020、顶环和支承；再点“豆路与双摄”，拖动进度到“双摄抓拍”；点“聚焦抽拉闸与双球头”看一只舵臂如何带直线滑片；“部件拆解”可对照BOM编号，点击实物外形查看说明。相机、舵机、花键舵臂、球头、灯槽、PCB和木板是有细节的外形重建，并非原厂CAD。

动画总长18秒，仅用于讲解。**落豆段按12倍慢放**，不代表机器速度；A/B图和疑似结果为预设，不能作为模型运行证据。透视斗壁为教学效果，实物PP不透明。连杆按50mm球心距约束计算，不表示球头实物、公差、全行程干涉或扭矩已验收。

## 小抽拉闸怎样做

H36选6061-T6平板29.4×82×2，去毛刺、倒钝，两面平。H38两根10×85间隔条用PP2叠PET0.3，厚2.3；上下PP3盖板夹出通道，左右各0.3、上下总0.3名义间隙。薄PP焊后翘曲和实际板厚可能吃掉间隙，所以导向部分螺栓夹紧，不焊死；滑片、PET垫条拆下后才能焊固定管道。冷却后不接舵机，先全程手推，不顺就修平/配垫，不能用舵机硬磨通。

闭位铝片前缘Y108，孔前缘113、后缘127；片从后方进入前方固定盒内，覆盖孔。开位前缘127.749，露出整个孔；约20mm有效行程。前外壁Y93–95封闭连续，闸片不伸到豆路外。上下短管与前面外封板连成固定壳体；这是**固定前方外壳连续**，不是声称内侧一张薄板在闸缝处无缝穿过。内焊筋、凸边和铝片倒角仍要实豆确认，缓关不能保证不卡豆。

H10淘宝可分别买“MG996R金属固定支架”“6061铝板60×60×3”“2020两孔加强角码40×40×4、宽20”。加强角码以两颗M5/T螺母锁右后立柱，再托铝转接板Z280.2；标准支架承舵机安装耳，轴目标(170,180,331)。图中是安装原理，**不是最终可钻孔图**。先拿实物量轴偏置、安装耳和支架高度，再定长孔与垫高，保证不侵入拍摄窗。

H11仍**只买一只**MG996R匹配25T金属直臂，使用轴心距16mm的M3孔。H37买一套“M3球头连杆，球心距50mm，可调约±3”，包含**一根杆＋两颗球头**。问卖家要“装好后两球心中心距50”，50mm裸螺杆通常不合适。H12用M3×8候选隔柱加实配球头螺柱/垫片，把闸片端球心抬到与舵臂球心同高337.5；收到件后量中心高度，不能硬掰成斜平面。

几何检算采用舵机轴(170,180)、R16、球心距50、滑片球心X110。闭位几何角−40.706°时球心Y184；开位0°时Y203.749，行程19.749。球头孔位在闸片横向中线、距前缘76。几何角是图纸坐标，**不是舵机绝对角或已标定PWM脉宽**。限位检测闸片尾部外侧小旗，固定开关要实配；不能让开关硬限位承受舵机堵转。

## PP裁切与焊接边界

采购PP2 300×300、PP3 300×300各一片。PP2上斗四块100×100毛坯，下斗四块75×70毛坯；余料做短管、前封板、小耳。PP3顶环176×196、上下盖各50×85、后承托176×50、相机载板60×60两块可排入一片300方板：顶环占176×196；右侧124mm宽放盖板/载板；底部104mm余带放后承托。保留切缝和修边，先纸样排版。

上斗内表面理论前/后梯形为上80、下18、斜高95.86；左/右上80、下14、斜高95.19。下斗理论上64、下30、斜高62.36。**这些内表面数值不是已补偿2mm板厚/包边/焊筋/收缩的最终裁线**，裁切表明确给毛坯。先用纸板在18×14短管与80口环上试拼，选前后片外包左右片，按实物板厚修边至内孔；控温焊枪先用同料试焊，外侧点焊定位、对称短段焊、冷却后量内口，再完成外焊。内部清除凸焊筋；闸缝/导向面不留焊瘤。不提供假装可直接1:1下刀的模板。

## 接线与运行边界

YU2405机外24V5A → 三支路：24V常亮灯、TPS5450候选成品板调5V给BOX Type-C1与AHCT缓冲、好盈30607000 UBEC5A设6V独立给MG996R。两摄从兼容CSI供电。舵机电流独立回UBEC，信号参考共地。J10没有电源/GND；参考地从已读BOX原理图J6 PH2.0口1第2脚引出，方向须实核。

候选信号沿用H1已读BOX原理图：J10-1 GPIO25/PWM5 → SN74AHCT125N单向缓冲 → 舵机；J10-2 GPIO24关限位，J10-3 GPIO23开限位；J10-4 GPIO22经2N3904控制缓冲使能。KEY0=GPIO34人工准备/确认，KEY1=GPIO35软件停止；KEY2=GPIO0保留，不作普通按键。引脚复用、接口针1、使能默认态和脉宽均未上板验证；**不能抄C6引脚**。

灯8W、逻辑5V×3A、舵机6V×3A持续/5A短峰，按转换效率0.8预算：持续(15+18)/0.8+8=49.25W，短峰(15+30)/0.8+8=64.25W。不是实测，未证明某淘宝TPS5450成品板可连续3A或双摄运行无压降；整板SKU、保险、线径、插头、温升仍按电源详图/实测确认。H3无额外控制板。

## 先验证拍得到，再加工整机

1. 只接BOX和两摄，在台面确认两CSI映射、实际镜头对焦、豆粒像素密度、两路预览＋主屏可同时运行。记录已装CanMV/nncase版本，不升级用户环境或烧卡。
2. 确认**现有BOX固件能设置并维持短曝光**。嘉楠官方社区答复提示曝光控制API在V1.6增加，不能把最新通用文档API当作本板旧版固件可用。本项目资料盘有v1.2/v1.3例程，不代表板上版本；先查实际能力，缺API时单独评估适配，不能直接刷写。[官方版本答复](https://www.kendryte.com/answer/questions/10010000000012329)
3. 两摄先连续采集，用纸管在Z326左右逐颗放豆，在Z260处拍摄。按理想无碰撞自由落体，66mm落差中心速度约1.14m/s，Z285–235仅约44.8ms；30fps**若能达到**也只约1.34帧间隔。0.2mm运动拖影需要约176µs以下，100–200µs只能作初始试验范围，实际亮度/噪声/滚动快门须看原图。不能等开闸后才启动相机，更不能用IDE预览帧率冒充采集率。
4. 每次人工只放一颗，给一个cycle_id；两路新帧各取清楚ROI、核单颗和同周期配对，再推理并保存。时间/位置配对阈值待定；未做硬件同步，也不宣称完整覆盖两面。任一路缺图/糊图、多豆或配对不确定一律待复核。落豆无法撤回，所以缺图后暂停下一循环并保存未完成记录，不能写成“失败仍保持本豆在闸上”。
5. 缓存有上限，例每摄最多3张320×320 RGB ROI，共1,843,200字节；仅是可计算的队列候选，还须核主屏、采集池、KPU和实际ROI的总内存，不能直接缓存两路全部原帧。
6. 图像成功后才手推闸片、断开连杆做空载小角度舵机，标定两限位与超时，再连接单槽放实豆。启动不自动开闸；缺流、保存失败、限位矛盾或卡豆撤销下一次释放许可。KEY1不是硬急停，撤销PWM也不保证舵机立即卸力或闸门自闭。
7. 关闭速度可通过分步更新位置目标放慢；先确认豆已进杯且通道空，动画缓关3.5秒仅讲解，不作为固件参数。卡豆停止，断6V后手动清理，不能让缓关持续顶豆。

版本来源：[正点原子BOX双CSI原厂介绍](https://wiki.alientek.com/docs/Boards/Kendryte/DNK230D/start-guide/k230d-box-introduction/)；候选引脚基于H1已记录的DNK230D V1.0原理图及校验值，见独立基线。以上估算不代表实机帧率、可用图率、识别准确率或比赛成绩。
