## 先区分旋转与平移

MG996R输出旋转不意味着闸片必须旋转。V4.4文字已经要求前后抽拉，但第03图只画一槽侧视，没有交代横向居中推力和防偏转约束。若把闸片直接固定在舵盘上绕轴扫过五槽，开口会先后出现；若闸片沿槽列左右移动，也会依次露出。偏心推拉且导向不足，则可能偏转、卡滞。仅凭靠近舵机不能推断哪个槽必定先开，取决于具体几何。

修正目标：闸片位于水平面，沿前后方向平移；其直线前缘始终平行于五槽排列方向。五槽在闸门位置处的前后边界必须对齐。理想刚性几何下，五槽有效开口随同一位移同步变化；不保证五槽第一颗豆同时下落、等流量或逐粒分离。

## 首选：保留一个MG996R，居中连杆驱动导向滑架

传动链：固定舵机 → 舵盘曲柄 → 两端可转动的连杆 → 后部刚性横梁/滑架 → 整片闸片。闸片不能直接锁在舵盘上。推拉连接点位于五槽宽度中心线附近，后横梁把载荷传给整片薄闸片。

- 左右各设前后方向的导向，导向长度与前后支承间距足以抵抗偏转；同时限制闸片抬起、俯仰。两块短挡块不能自动等同完整直线导向。
- DIY可先用可调POM/U形导槽；一侧作定位基准，另一侧允许小量装配调整，锁定前手推全行程。不要靠把两边同时夹紧来消除晃动。导槽避开豆屑积聚区并可拆清理。
- 当前1kg装豆首样改用110×45×2mm的6061-T6闸片，120×30×3mm转接板连接两侧MGN9H，10×10×2mm角铝加强/连接闸片。原薄POM方案仅作历史，不再默认采购。若载荷下挠曲，调整支承/材料再测，不直接扩大舵机扭矩。
- 原1.3–1.6mm数值只能视为导槽高度起试值，不能充当横向防偏转公差；须按实物片厚、翘曲及豆屑验证。
- 舵机与导向固定在同一刚性机架。优先让连杆两端在同一运动平面；可在后部滑架设置抬高连接耳，使水平舵盘/连杆同高，滑架导向承担该连接耳产生的俯仰力矩。连接耳在豆路后方。
- 原轴z315、闸片z292的23mm落差不是可直接下单的连杆尺寸。球头只允许转角，不会消除斜拉的竖向力，也不会导向。支架高度、轴向、横梁、连杆长度与后摄视锥须联合纸样复核；原第03图不得作为最终孔位加工图。
- 开/关限位检测实际滑架，不检测舵盘角度；机械保护挡块留在正常标定行程外。保持独立6V供电；超时/夹豆停止、不持续加力，不宣称失电自闭。

## 行程和曲柄：当前16mm，以下12.5mm为历史推导

沿运动方向的有效开口深度记为d，关闭覆盖余量c、打开退出余量o，则所需行程s≥d+c+o。d=12mm、c=o=1.5mm时，s=15mm；余量尚未验证。若增加覆盖或边缘结构，须重新计算，不能只按12mm开口就定12mm行程。

对于居中、共面、无偏置的理想曲柄滑块，r=12.5mm且曲柄在横向基准两侧对称转动±37°，对称端点的连杆投影项相消，行程为2r·sin37°≈15.05mm。须保证连杆足够长、全程无干涉，并避开曲柄与连杆共线的死点。原装置存在高度偏置时，不能直接套用这个结果。±37°是机构相对角，不是PWM命令角；脉宽与端点按实际舵机和滑架限位标定。

舵机扭矩只能作为参考。TowerPro原厂列6V堵转扭矩11kgf·cm，约1.08N·m；在12.5mm力臂处对应约86N切向力，仅为堵转附近的参考，不是滑架连续可用推力，更不是用户15.58元兼容件的实测性能。需要量闸门载荷下的启动力、运动阻力、动作时间、峰值电流和温升。卡豆力不作为正常推力需求。

## 同一舵机的其他传动方式

| 方式 | 适用条件 | 代价/缺点 |
|---|---|---|
| 居中曲柄连杆＋导向滑架 | 当前首选；加工和控制相对简单 | 速度随角度变化，有侧向力；需联合设计杆长与支架 |
| 舵盘销＋横向长槽滑架 | 后部空间较小、可做耐磨销/滚轮 | 长槽承担横向滑动，存在磨损和间隙；不直接在薄POM闸片上开驱动槽 |
| 齿轮＋居中齿条＋导向滑架 | 想让位移和角度近似线性，能稳定安装齿条 | 需要额外啮合件和防尘，间隙/齿条安装影响重复性；齿条仍不能替代导向 |
| 一根横轴带左右等相位曲柄 | 横梁很宽、已出现明显左右扭斜 | 同一机械轴同步可行，但增加轴承、曲柄和安装校准；当前110mm宽先不增加复杂度 |

## 换执行器是否更好

| 方案 | 可能收益 | 新增成本与边界 | 当前判断 |
|---|---|---|---|
| 保留MG996R | 复用已选供电/PWM路径，完成15mm级开关动作 | 需验证兼容件性能、齿隙、温升与寿命 | 先做样机 |
| 换更可靠的位置舵机 | 型号资料、重复性、耐用性可能更好 | 同样需要连杆与导向；电压/电流/信号须重核 | 现舵机实测不合格后评估 |
| 步进电机＋短行程直线模组 | 便于设置中间开度、速度和加减速 | 驱动器、供电、回零、控制和防尘增加；开环失步不能当作到位，仍要滑架限位 | 需要反复可控中间开度或长期运行时再评估 |
| 微型电动推杆/直线伺服 | 原生直线输出，减少曲柄设计 | 按实际15mm有效行程、带载速度、占用空间、反馈、工作制选型；自锁型不能默认失电关闸 | 有合适短行程型号时再比较 |
| 电磁铁＋回位弹簧 | 可实现快速两态动作 | 冲击/热、全行程力与弹簧复位须测；夹豆仍可阻止复位 | 当前不优先 |

同步问题先由几何与导向解决。换成更大扭矩电机不会修复歪斜闸片。当前没有足够证据指定替换型号或确认MG996R推力足够。

## 初学者验证顺序

1. 不接舵机，制作五槽出口纸样和全宽滑片样板。确认五槽开口在同一前后位置，前后平移时整条前缘同时扫过五槽，避免左右抽拉。
2. 做实际导向和后横梁，手推到关闭/半开/全开，在各槽测前缘相对固定基准的位置。先要求无明显左右超前、翘起或卡滞；记录最大差值，不能用终点限位证明中途同步。
3. 装舵机，独立6V空载小角度试动；对照滑架标定两个端点和超时。手机俯拍慢动作，对比1/3/5槽开启与关闭的几何时刻。视频时间分辨率决定可报告的同步误差下限。
4. 一槽少量豆开始，再扩到五槽；分别测空斗、半斗、满斗，不连续硬顶被夹住的豆。偏转→先改导向/横梁；阻力大→查间隙/豆屑/支承；手推顺但舵机不合格→再比较执行器。
5. 记录启动力、带载动作时间、电流、温升、夹豆和关闸后的残流。五槽首豆时差与闸片几何同步分开报告。尾流、架桥和豆体姿态仍需送料与视觉验证。

几何敏感度示例：若跨110mm宽的前缘偏转0.5°，两端前后位置差约110·tan0.5°≈0.96mm；这只是说明小偏转也可见，不是已测误差或验收阈值。
