## 为什么这样连接

旧渲染方块三通/四通没有与现有型材核对的料号。本次用460连续立柱＋内侧两孔90°角码，无需端面攻牙、易调整。代价是角码占内部空间，要校方、复紧，避让称台。隐藏锚栓外观更简洁，但需匹配槽系/工艺孔，留到样机尺寸冻结后考虑。不能凭1kg豆料的9.81N静载宣布机架刚度合格。

骨架外220宽×240深×460高，18根：460×4、200×6、180×8，净4480mm。顶框440–460，底框0–20，中框304–324，相机梁221.25–241.25。中框前后180梁由旧内缩位置改为Y0/220，形成外露黑色腰线；按钮移到Z273，按实物核背部空间。

主斗木壳外158方/内146方，高110，底330顶440；托耳Z324–330，上口PP圈顶442。成品/裸框同一视角同一比例，仅水平平移750px；不分别缩放，不以外观渲染加工。

## 三面木板与固定

左/右/后三面延续至底部，在实际梁处分成9块外面板；前下留取盒口。板厚6，面内凹约1、边缝约2，角部由黑色2020柱构成，木板不在外角拼接。尺寸/排版见制作指南与更新后的[裁切表](../assembly-v4.5/cut-list-v4.5.csv)。共15块木件，800×600×6一张，或两张600方替代。

F11用20×20×2内角片背托，名义11mm隔距及M3×25从板面穿出；隔距先用角部样件按实际角片调整。32个木板支点＋2个前遮光条支点，买40套。F08只管料斗木壳/托耳。面板不是经过验证的承力蒙皮。

只补同截面/槽型黑色欧标2020净长180mm四根。已有4020＋补720＝成品4480＋锯屑30＋余料230。若买原棒替代，可让卖家由750mm切4×180，但需确认实际锯缝/修平量；不与四根成品重复购买。400不能切200+200。要求净长建议±0.5mm，同组两两等长优先，端面去毛刺；这是采购要求，须卖家确认。

## 角码和装配

底8＋顶8＋中8＋相机4＝28套使用，买32套；两孔90°角码约20腿长/宽不超20为布局起点，螺钉与T螺母各64，必须按实物槽口/角码厚度配套。不能仅凭“2020欧标”推定槽5/槽6互换；旧item槽5料号不是本版默认。端盖4、外套橡胶脚套4；不把端盖当承重脚。

先松装上下框，测对角线校方，再中框/相机梁。称台固定底板四角25方只作角码净空核对区，按实物决定是否切角，不直接抬高称台凑空间。冷装料斗、断开舵机手推15mm，之后才做分级载荷与单槽联调；称重另验零点/重复性/旁路。相机、MG996R、传感器与供电块均有实物待核项。
