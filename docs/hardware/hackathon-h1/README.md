## 为什么采用侧摆挡片

只手投一颗，不需要长滑闸、双导轨和球头短杆。固定PP短斜槽的末端由一片轻PP挡片挡住；豆停止后，固定相机拍当前可见面。MG996R的25T直舵臂经小角铝直接带挡片向侧后方摆开，豆沿槽滑入杯。固定槽底和相机不跟舵机动，拍照期间不动作。0/90是相对几何，实际脉宽与动作方向空载标定。

本版删除C6、称重、第二相机、红外对射、PBT刷、大料斗、第二屏、联网和两板UART协议。已有这些件保留，不丢弃。没有自动分选，正常/疑似/拒判都进入同一杯。单面图像不等于整颗豆全部表面或内部质量。

## 材料与尺寸

框架继续用现有黑欧标2020，外220×240×460，12段：立柱460×4、宽梁180×4、深梁200×4。现有460×7、400×2足够：

1. 4根460保留整根当柱。
2. 另3根460各切200＋180；每根余80扣锯缝/端面修整。
3. 1根400切200＋180，余20扣锯缝；另1根400保留。新型材订购量为0；若已按完整版切好则优先取对应成品，不再切一次。

H16海洋板6mm固定平台3片176×196：底面Z20、180、344。工作板50×45落豆孔，全局左前角X85/Y122。PP3底座80×110，位置X75/Y65/Z186，开40×40孔全局X90/Y124。两孔重叠，槽出口下不能被支承板堵住。杯约100×100×80，底X60/Y95/Z26，直接放固定底板，不安装称重件。

停豆槽名义内宽24。PP3底板按**板面24×60**裁，35°起试：水平长49.149、高差34.414。下游端Y124/Z220；上游Y74.851/Z254.414。两片PP3侧支承的底为水平49.149，上游高79.414、下游高45；底面都Z189，顶面比槽底高14。3片组合成短槽，两侧也承担下支承，底边用小角件/螺钉固定底座。H30含小角件安装螺钉，小角件由H12角铝余料另切2只20×20×2宽15并列入裁切表，不能把它们当成挡片角件的一部分重复使用。

PP焊接先小样，槽内焊筋修平后有效宽先验≥20，不把焊筋留成卡豆台阶。原料用PP-H3 200×200候选一片，与60方相机载板一起排版；若已有余料先排版核尺寸。焊接缩水/翘曲不能靠强拉螺钉纠正。坡度先用少量实豆试到能滑至末端，才固定支承；35°不是流动性保证。

挡片PP3 46×18，闭合XYZ=(94,124.5,220.5)，横跨出口。摆轴目标(140,126,240)，16mm舵臂孔目标(124,126,240)。挡片底与槽底名义0.5mm，实配不刮底且不漏豆。90°打开后挡片包络X约138.5–141.5/Y126–172；后遮光片Y190，名义后隙18。旗片固定在挡片刚性角件上，两个开关固定在支架；检测实际挡片动作，不能只看舵机命令。MG996R机身/轴偏置、角件方向、旗片碰轮与全部孔位都按实物试配，当前不是放行加工图。单颗轻载，不沿用完整版1kg承重推算；人工不得按压挡片。

相机镜头朝下，光轴X110/Y112、镜头Z320起试，正对下游停豆区；镜头至豆约80–140mm调焦范围只是起点，按原镜头近焦/畸变实拍决定。40×40×25是模组占位，非所购厂家尺寸。H18相机支架不得由CSI排线承重。黑PP2遮光：左右120×100、后110×100，分别X65、175/Y190，Z225–325；前方敞开人工放豆。遮光片用可拆小夹件/魔术贴固定，先核不碰灯/相机/闸片。

## 电力逐步接法

YU2405保持机外，只将24V低压引入绝缘配电。主正输入4A保险；分别经灯1A、5V降压输入1.5A、UBEC输入3A保险。保险是试制线束保护起点，实际启动电流和温升另测；不是卡豆保护。

- 24V → 两段灯带（总有效长0.2m，功率≤4W预算，实际剪切点和功率待核）。
- 24V → TPS5450整板候选 → 5.00V → BOX **Type-C1**和缓冲IC。Type-C2没有供电功能。逻辑预算3A，完整整板SKU未定，禁止把裸芯片当模块。
- 24V → 好盈UBEC5A 30607000/2–8S候选 → **6.0V** → DC≥12V/5A手动支路开关 → MG996R红线；棕/黑返回UBEC OUT−。先断电设6V跳帽、实测电压再接。
- 舵机6V/GND附近并1000µF/16V，注意极性；缓冲IC14/7旁100nF。电容不能替代合格电源与线径。

所有非隔离支路共参考地。BOX GND从J6（PH2.0口1）的**2脚**引出到信号参考节点；J6其余5V/TX/RX三针不接，做绝缘，实物针1朝向先核。舵机大电流返回必须从独立粗线回UBEC，不走BOX地针或杜邦。**5V、6V、24V正端不能并接**。USB调试时不另一路5V反灌/并联。YU2405 DC头、极性、厂牌和AC线以实际订单核，不套其他卖家同名资料。

预算：5×3/0.8＋6×3/0.8＋4=45.25W持续；舵机短峰按5A时60.25W。尚未测压降/纹波/温升，不因此宣称电源实测通过。

## GPIO、信号缓冲、限位与按键

已查本地ATK-DNK230D V1.0原理图：GPIO25明确列PWM5，J10引脚1/2/3/4分别IO25/24/23/22，BANK1为3.3V。原理图SHA256记入独立基线。针1位置必须按板卡丝印与连通性核；排针J10没有GND或电源。目标板FPIOA复用、实际固件版本尚未上板验证。

| 功能 | BOX接点 | 接法 |
|---|---|---|
| 舵机PWM | GPIO25 / PWM5，J10-1 | 50Hz，先经1k到AHCT125的2脚1A；该脚另10k下拉GND |
| 关限位 | GPIO24，J10-2 | 内部上拉，经1k到NO；COM接公共地，触发0 |
| 开限位 | GPIO23，J10-3 | 同上 |
| 信号使能 | GPIO22，J10-4 | 经4.7k到2N3904基极，基极另100k下拉；E地，C接/OE1 |
| 拍摄/确认 | 板载KEY0 / GPIO34 | 低有效；忙时重复按不新增动作/样本 |
| 停止 | 板载KEY1 / GPIO35 | 低有效；软件停止，非硬件急停 |
| 保留 | KEY2 / GPIO0 | 涉及启动模式，不占用 |

H22缓冲板采用TI SN74AHCT125N DIP14（H23–H27是其构成件）。14脚5V，7脚GND；1脚/OE经10k上拉5V默认禁能，NPN拉低才使能，GPIO22不直接接5V上拉节点。3脚1Y经220Ω去舵机信号。闲置/OE脚4/10/13接5V，闲置输入5/9/12接GND，闲置输出6/8/11悬空不接。不要用74HC125普通CMOS门限直接替代AHCT/HCT。三极管按实际厂家TO-92脚序识别E/B/C，不照通用平面方向猜。H22只买加工服务/洞洞板与器件一次，不重复采购成两套板。

上板先不接舵机，核`fpioa.help(25)`及PWM5可用性，确认没有别的PWM通道占用共享频率；本版不启用蜂鸣器。用示波器确认50Hz、脉宽和禁能，再小角度空载；不能用软件模拟替代实测。MG996R可能在上6V时产生抖动，默认禁能不保证完全无机械动作；首次通电将连杆/挡片脱开、手离开机构。闭合脉宽、打开脉宽、动作超时均留空待标定，没有冻结值。

## 正常操作与失败处理

1. 舵机6V开关先断开，量5V/6V，检查限位与机械可手动顺畅。应用启动不自动开闸/找零，关位不明确时禁止自动循环。
2. 关限位有效且开限位无效，单摄/模型/TF可用后，提示人工逐颗放豆。手离开后按KEY0；拍照期间不动闸门。
3. 固定ROI检查明显空槽、多豆和模糊；这不保证检出全部贴连，由人工单颗确认兜底。失败则保持关并人工重放，不增加有效样本。
4. 用真实部署模型推理，保留原标签映射。存一张JPEG＋本地结果，先按100次样本上限；不保存全帧视频、不覆盖旧用户数据。存储或推理失败不自动放豆。
5. 正常/疑似结果显示后开闸；低置信记“拒判”，需要KEY0确认放走。拍摄/记录按cycle_id一次，动作次数不直接当豆数。
6. 开限位确认后放豆，图像空槽观察＋人工可见确认收尾。空槽不明确则保持故障；明确空槽后才关闸，关限位确认再允许下一颗。
7. KEY1撤销当前循环；只有确认空槽且控制链正常才允许有限时关闸，否则停住待人工。限位矛盾、卡豆、到位超时先停止新增动作，不持续加力；断开6V后排障。不是失电自闭，不自动恢复。

## 比赛验收与工作边界

先用固定豆/固定ROI跑通单摄、真实kmodel推理和BOX显示；现有模型文件不等于已转换上板。复用原训练成果，不为本次设计重训/升级环境。再无执行器限位模拟、缓冲信号、空载舵机、最后逐颗实豆，连续10次完成拍照/结果/证据/放走/复位，一一对应。必须展示拒判和失败处理，不把动画预置结果当真实AI。

本次交付是设计资料、BOM、图纸和离线教学动画，没有产品固件、烧录或硬件验收。`firmware/k230d/bringup/`已有用户新增工作保留不动。完整版目录保持原字节；只在公共索引/交接/根规则加H1入口，独立基线不替换完整版引脚。未自行提交/推送。
