# H1 拟真教学动画 · 2026-10-21

优先打开上级 `beanlens-realistic-h1.html`，单文件离线可用，无需安装依赖。本目录 `index.html` 是开发入口。默认显示舵机机构特写；可切换整机与分件，拖动旋转、滚轮缩放，播放或拖动时间轴。

## 本轮设计与实施

沿用用户已确认的 H1：单摄、单槽、人工逐颗、静止拍照、MG996R 直接侧摆放豆；BOX 同时识别、显示和控制。不是完整版的平移滑闸。尺寸从上级 `design-h1.json` 派生，不改原 BOM、加工图或固件。

采用本地 Three.js 0.160.1 绘制有安装耳、标签、出线的 MG996R；有花键轮毂、安装孔的单舵臂；有镜筒、PCB、排线的 GC2093；有屏框、按键、透明背板的 BOX；有槽口截面的黑2020、海洋板层边、PP槽和收豆杯。实物外形是识别性重建，非原厂 CAD。支架、角片、相机 PCB 和接口走线仍是示意，不能照此直接定孔。

实施顺序：

1. 以 H1 坐标建立组件及材质，明确固定架与旋转组件分组。
2. 加入整机／特写／分件视角，组件说明和 BOM 关联。
3. 用纯教学时间轴同步豆粒、舵臂、挡片、屏幕。相机和槽体保持固定，空槽后慢关。
4. 检查本地打开、播放/暂停/重播/拖轴、镜头切换、键盘/移动布局及渲染截图；记录实际结果。

## 观看边界

- 动画自动代演“人工放一颗、手离开、按 KEY0”，不代表实机自动送料或视觉已部署。
- 屏幕分类为预设演示；近景镜头光效只强调拍照阶段，实物灯带常亮，不表示闪光触发。
- 时长和 0–90° 是教学几何，非已标定脉宽、动作超时或工作速度。
- 支架安装高度、孔位和角片防转连接待实配；仅一只驱动舵臂。为显示内部，特写会隐藏遮光片、上部机架、相机与灯架；整机模式显示相机和灯架，并可恢复遮光片。
- 电源放机外，供电细节继续看原 `04-power.svg`、`05-signals.svg`；本页线束只示意走向。
- 本轮外形检查把关限位示意移到舵机侧，避免旧占位遮挡拍摄区；旗片与限位的具体触发接触尚未验证。铝转接板示意叠在PP底座上方，并以垫片支承另一侧，避免两个3mm板件重合；支架立边高度按此让位。这些是待实配的装配示意，未回填旧H1加工图，不得混用坐标直接定孔。
