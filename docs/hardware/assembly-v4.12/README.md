## 本版修正了什么

旧V4.8整机模型仍含主斗高110、小过渡斗、双法兰和PP叠片，现在整机图改为V4.11连续斗：内上136方、内下82×12，Z298.3→440、高141.7，PP2四壁连续。四个顶框金属托片托PP3顶环，木板不承担斗重。下方为PP6上座、PP10下座、PP2连续前/侧壁与2.3间隔；铝闸片从后方关闭、前承接覆盖1.5。前后10段PBT和4片PP3短分道单独在爆炸图表达；模型的刷毛/背罩仍为示意，孔位按样件。

对射为SEN0503，5V供电，50cm是5V条件参数。头部20×10×9及250线长由原厂资料给出；安装朝向/光孔偏置/支架孔未核。图中的Z277光束、头部放置与侧封片避让仍为试装目标，不能据外形断言通过。

主电源为用户选YU2405 24V5A/120W，适配器和低压配电盒都画在机外，删除旧整机“模块装在下部后电控托板”的主方案。YU2405外框为示意占位，不是供应商尺寸；实际厂牌、插头和极性到货核。5V路仍是TPS5450整板候选，6V舵机仍用UBEC5A/6V（好盈30607000/2–8S候选）。图11/12同步现行电源拓扑和SEN0503逐线接口，未擅改GPIO。

黑欧标2020外框220×240×460、18根型材、9木板和双屏位置保留。型材460×4、200×6、180×8；已有460×7/400×2时仍补黑色同槽型180×4。正确裁切：4根460作立柱；余3根460各切200+200（每根留60扣锯缝），得到200×6；2根400各切180+180（每根留40扣锯缝），得到180×4；加新购180×4即齐。旧料端面修整与实际锯缝在余量内核算，不拼接立柱。

## 双屏净空与装配

保留BOX原壳和内置2.4屏，前外压框/背框/四角软垫夹片；C6非Touch与内置1.47屏、侧外框/PP绝缘后框。两屏不额外采购LCD。屏后服务腔按连续斗重新计算：前面最不利Z402名义15.44mm，右面Z385名义14.44mm（均扣法向2mm板厚和水平4mm焊筋储备）。这些是空间预算，接头、天线、排线与拆装必须实际放得下。

## 电源端子与传感器接线

TB-A 1/2/3为24V正输入三路，经各自保险分别给灯、5V降压、6V UBEC；一段3位桥只接1–2–3。4/5/6分别为其返回端，另一段桥只接4–5–6。TB-B 1=5V+、2=5V返回、3=6V+、4=6V返回、5/6空，不装桥。不得把6格全部短接。舵机电流从独立6V返回，不经过C6板针；GPIO地保持共同参考。

SEN0503两头红线接5V、黑线接公共地，接收白线为A节点；拟10k到C6的3.3V，A经1k到GPIO20。原厂未给完整内部上拉图，先断开GPIO测遮挡/无遮挡两状态，确认3.3V域与实际极性后才接板；1k不负责把5V降成3.3V。完整测量步骤见[对射接线指南](../BEAM-SENSOR-20261012.md)。

## 动画的流程与边界

1. 上电握手，关限位确认，不自动开闸。
2. 人工确认盒已放好并空盒去皮；检查相机、模型、存储、限位。
3. 双摄连续采集；BOX只在有处理能力时给C6一次有限GRANT。
4. C6驱动MG996R经双球头杆开闸；五窗同步打开，光电仅经过提示。
5. 图像跟踪/双面配对/去重，保存疑似、拒判与抽查证据；所有豆落同一盒。
6. 有限送料到期或停止后撤销许可，尝试有限时缓关；关限位确认才发CLOSED。
7. 继续观察尾流与处理队列；对射安静不能单独证明排空。
8. 停料后等待称重稳定，合并双方完成状态，保存本地记录与有界网络摘要。

模拟24个唯一ID：正常候选20、疑似2、拒判2；净质量4.8g只是讲解数值。配对/模型/称重/网络不是已实现能力，示例秒数不能当固件超时。关闸卡豆没有CLOSED、不持续加力，失联/停止保留未完成记录、禁止自动恢复。软件停止不叫硬件急停，失电不保证闸门自闭。

## 重建与验证

build_assembly.py读取V4.8框架/木板数据与V4.11豆路，独立保有渲染器和网页模板；不执行旧生成器、不重写历史快照。运行export_checks.cjs导出12页PDF/PNG并检查装配交互、相同比例、流程和异常路径。再运行validate_design.py检查几何、BOM映射、本地链接与PDF页数，逐页渲染目视检查。使用rtk前缀和Bundled运行时，不改用户训练环境。
