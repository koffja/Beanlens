# K230D BOX 固件规则

先读根目录 `AGENTS.md`、硬件基线和固件验收路线。本目录目前没有 BeanLens 可执行固件。

- 目标为正点原子 K230D BOX，优先从用户已有、匹配的 CanMV 官方例程确认 API。厂商资料只读；产品代码写在本目录。
- 先记录实际板端固件、CanMV 与 nncase 版本，再确认显示、CSI1/2、UART1、TF 目录。不能把资料盘 v1.3 当实机版本。
- 主屏承担分类统计与证据；机械动作由 C6 执行。BOX 只签发有期限、绑定会话和序号的送料许可；不绕开 C6 的停止/限位逻辑。
- 双摄 API 支持、实际同时帧率、硬同步、手动曝光/白平衡分别验证。相机持续采集，不用同步 HTTP/API 请求阻塞采集。
- 管理 128MB 内存：原帧、裁图和推理缓存均有上限，记录峰值；不累计整批全帧，不假定两路满分辨率加模型可同时常驻。
- 单豆完整裁图、输入颜色通道/缩放/归一化、标签顺序必须与训练一致。CLS 不解析成 DET，ONNX 不当作 KPU 可执行模型。
- 先做静态单图 PC/ONNX/KPU 对照，再接逐槽跟踪和双面配对。未通过转换/量化对照，不报告端侧准确率。
- 推理或存储异常停止发新送料许可，保留已完成证据与未完成原因。复位、会话改变后丢弃旧许可与旧待执行序号。
- 发布物至少记录应用版本、板端版本、kmodel/标签/预处理校验值及上板验证记录；当前这些值为空是正常的未完成状态。
