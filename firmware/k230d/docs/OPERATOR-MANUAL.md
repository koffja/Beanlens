# BeanLens K230D 操作员手册（草稿）

状态：按主机逻辑层的行为起草。屏幕上的实际布局、按键位置、开机耗时都还没在板上核对，
上板后请逐项对照并修改。标注「未验证」的内容不要当作结论。

## 1. 开机

开机后进入待机页。固件启动时会自动恢复上次没处理完的数据：
- 上次保存到一半的队列项会回到「待保存」状态。
- 上次扫描中途断电的会话会变成「未完成」，待机页出现横幅「上次扫描未完成（时间，约 N 颗），查看 / 丢弃」。

开机到可操作需要多久：未验证。

## 2. 开始扫描

1. 在待机页点「开始扫描」。
2. 向豆路持续投豆，豆子自由下落，由前后两路相机抓拍。
3. 队列满 100 条时不能开始，屏幕显示「队列已满（100 条），请清理或恢复网络后再扫描」。需要先在设置里清理。

## 3. 停止与查看结果

点「停止」进入结果页，计数此时冻结，不能继续扫描；要补豆只能放弃后重新开始。

结果页并排显示三个数字，名字固定：
- 豆粒总数
- 瑕疵豆总数
- 配对不明

「预览计点」带「临时规则」角标，只用于屏显，最终成绩以服务端按最新规则计算为准。
16 类默认只显示非零项，零项折叠，可按组展开。

如果配对不明超过豆粒总数的 20%，屏幕提示「豆路对准或光照异常」，请联系装调人员检查，不要直接保存。

## 4. 保存或放弃

- 本地保存：记录进入本地队列，回到待机页。若 16 类之和大于豆粒总数，固件拒绝保存并提示原因，停留在结果页，请联系技术支持。
- 放弃：需要二次确认，确认后本次结果不保存。

## 5. 未完成的扫描

待机页横幅可以「查看」或「丢弃」。未完成会话永远不能保存入队。

## 6. 设置

- 样品重量：默认 350g，可设 300–400g，越界会被拒绝并提示范围。
- 队列管理：查看每条记录的状态，可删除待保存或失败的项；正在保存和已保存的项不能删除。失败项可以看到原因。
- v1 没有 WiFi 和配对入口。

## 7. 诊断页（装调用，平时不进入）

从设置进入，手动开启预览后以约 2 帧每秒显示前后两路静态画面，叠加检测框。
扫描中不能进入。离开页面后预览立即停止。
