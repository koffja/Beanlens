# K230D 固件测试套件

票 08 完整的 UI 逻辑层，纯 Python，不依赖硬件或 LVGL。

## 运行测试

```bash
cd firmware/k230d
rtk python3 -m unittest discover -s tests -p "test_*.py"
```

## 测试覆盖范围

- **业务核心**：会话生命周期、瑕疵分类、计点规则、队列管理、会话恢复、配置管理（46 + 34 + 15 + 44 + 23 + 13 = 175 个用例）
- **UI 逻辑层**：待机页、扫描中页、结果页、设置页、诊断页、主控制器与完整流程（28 + 13 + 26 + 10 + 22 = 99 个用例）

共 274 个测试用例，总运行时间约 3 分钟（含慢速 JSON 序列化）。

## 注意事项

- 所有测试用 Python 标准库子集编写，避免 MicroPython 不支持的特性（dataclasses / pathlib / typing）
- UI 逻辑层与业务层完全解耦，业务模块（app/core）不导入 UI 模块（app/ui）
- 界面层不含联网、配对、WiFi 或绑定账号的入口（v1 范围外）
- 诊断页的预览骨架（2fps 限速、离开即关相机、扫描中禁入）已有主机测试，用假相机验证；
  真实双摄预览与检测框叠加只能上板验证（票 10）
- 全量测试 441 项，主机实测 3.5 至 7 分钟（221 秒与 404 秒各一次，随机器负载波动），不是死循环；
  单个模块请用 `discover -s tests -p "test_xxx.py"`，不要用 `unittest tests.test_xxx`（部分旧测试用裸导入）
